What each venue expects

26 journals and conferences, grouped by field. Each page gives the reference style, the BibTeX style file where one exists, the template, and a link to the venue's own instructions.

  • MISQ: MIS Quarterly
  • ISR: Information Systems Research
  • JMIS: Journal of Management Information Systems
  • JAIS: Journal of the Association for Information Systems
  • EJIS: European Journal of Information Systems
  • ISJ: Information Systems Journal
  • ICIS: International Conference on Information Systems
  • HICSS: Hawaii International Conference on System Sciences

Security

  • IEEE S&P (“Oakland”): IEEE Symposium on Security and Privacy
  • USENIX Security: USENIX Security Symposium
  • ACM CCS: ACM Conference on Computer and Communications Security
  • NDSS: Network and Distributed System Security Symposium
  • IEEE TDSC: IEEE Transactions on Dependable and Secure Computing

Machine learning and NLP

  • ICML: International Conference on Machine Learning
  • ICLR: International Conference on Learning Representations
  • ACL (ACL Rolling Review): Association for Computational Linguistics conferences, submitted through ACL Rolling Review
  • AAAI: AAAI Conference on Artificial Intelligence

HCI and data mining

  • CHI: ACM CHI Conference on Human Factors in Computing Systems
  • KDD: ACM SIGKDD Conference on Knowledge Discovery and Data Mining
  • WWW (The Web Conference): The ACM Web Conference

General science

  • PLOS ONE
  • Nature
  • Science
  • PNAS: Proceedings of the National Academy of Sciences

Publisher series

  • ACM CSUR: ACM Computing Surveys
  • Springer LNCS: Springer Lecture Notes in Computer Science
