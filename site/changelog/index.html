October 8, 2026
Update

Legroom 1.2.0

New: the Uninstaller. Choose Uninstaller in the menu bar dropdown, pick an app, and Legroom lists the files it keeps in your Library folder, with sizes. Files named exactly for the app start ticked, and nothing moves until you confirm a sheet that measures each item again. Everything goes to the Trash; nothing is deleted. A second tab lists support files left by apps that are already gone. Like cleaning, the Uninstaller works during the trial and needs a license key after it. Find Files now says why nothing can move after you choose which duplicate to keep, and its Move button shows how many files it will move. Legroom.

Update

Keyfeel 1.3.0

Trackpad gestures can now have their own sound, the way shortcuts do: Mission Control, Application windows, Show Desktop and switching desktops. Mission Control has a sound by default, and each can be changed or loaded from your own file in Settings, Shortcuts. Switching desktops works straight away; the other three need the Accessibility permission. Headphones and speakers now keep separate volumes, and Keyfeel switches between them when the output changes. Version 1.2.1 fixed silence after switching the output, for example from headphones back to the speakers.

ModernTex 1.3.1: one Settings window, and control over how the editor looks

Settings now open with ⌘, like any Mac app, and hold everything in one window: General, Editor, Colors, Writing Checks, AI & Account and Compile. September 13, 2026
Update

ModernTex 1.3.0: a real Table Editor

Table Editor (Compile menu, the toolbar's Table Editor button, or ⌘⇧T): paste a range copied from Excel or Google Sheets and it lands in the right cells, growing the table only if the pasted data is bigger than what's there — never smaller. Drag a column's edge to resize it; press Return in a cell for a real line break, which turns that column into a wrapping paragraph column automatically. Excel-native keys throughout: Return confirms a cell and moves down a row, ⌥Return is Excel's own line-break chord, arrow keys move between rows, and a smart ⌘V detects a real pasted range versus a single value. Set a table-wide font size and family for a dense results table. Pick a table already in your document from the Tables menu and edit it in place, or start from a preset. Read more about it, and the TikZ Designer from the last release, on the blog. Delivered through the app's own update check.

September 12, 2026
Update

ModernTex 1.2.0: a visual TikZ workflow

TikZ Designer (Compile menu, the toolbar's TikZ Figure Editor button, or ⌘⌥⇧K): build a diagram by dragging boxes and arrows instead of writing TikZ by hand — real colors, resizable boxes, drag-to-connect with a live preview line, double-click to rename, undo, duplicate, a dashed Note box for callouts, and presets to start from (flowchart, pipeline, state machine, tree). Pick a figure already in your document from the Figures menu and edit it directly, or insert a new one — either way it drops in plain, readable TikZ. New and still evolving, so double-check the generated code. TikZ Preview (⌘⌥K) renders just the tikzpicture under your cursor on its own, with instant warnings for a missing semicolon or an unclosed brace before you run a full compile. Also in this release: a proper in-app User Guide, and the license keys described below. Delivered through the app's own update check.
