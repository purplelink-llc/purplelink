VTT to SRT

Convert WebVTT (.vtt) captions from YouTube, Zoom, Teams or a course site to SRT, the format video editors and most players take. Speaker names are kept, and the repeated lines of auto-captions are merged. The file is read on your device. Nothing is uploaded.

    How it works

    WebVTT and SRT both list captions with a start time, an end time and text. This page reads the WebVTT file, skips its header, notes and style blocks, and writes each caption as a numbered SRT block with times like 00:01:02,500.

    Meeting and lecture captions often name the speaker with a voice tag. With the first option, the page writes the name before the text when the speaker changes, since SRT has no voice tags. Styling, colors and the word-by-word timing tags of auto-captions are removed; bold, italic and underline stay.

    YouTube's automatic captions scroll: each caption repeats the line above it, with a flash of a few milliseconds between them. Converted as they are, every line appears twice. With the second option, the page drops those repeats, but only in files that carry auto-caption timing tags, so two real captions that say the same thing are kept.

    How to convert VTT to SRT

    1. Get the captions. Download the .vtt file from YouTube Studio, Zoom, Teams or your course site.
    2. Check the options. Keep speaker names and merging on for most files.
    3. Add the file. Drop the .vtt file on the box, click it to choose it, or paste it.
    4. Download. Download the .srt file from its row.

    Limits

    • Up to 5 MB a file.
    • Positions, alignment, regions and colors are not part of SRT, so captions show at the player's default place and color.
    • SRT has no way to show a literal < followed by a tag name, so such text can look like markup to some players.

    Questions

    Are my files uploaded?
    No. The page reads each file with your browser and converts it in a background worker in this tab. There is no server step. The meter under the drop zone counts the bytes the page and its worker send while they work, so you can check this yourself. The only things the page downloads are its own scripts.
    Why does every line appear twice in my YouTube captions?
    YouTube's automatic captions scroll up a line at a time, so each caption repeats the one before it. Keep Merge the repeated lines on and each line appears once, at the time it was first said.
    What happens to speaker names?
    A voice tag such as <v Ana> becomes Ana: before the text, written when the speaker changes. Turn the option off to drop the names.
    Will it work with Zoom and Teams transcripts?
    Yes. Both export WebVTT with speaker names, which the page keeps. For a plain text transcript without times, use Transcript Cleaner.
