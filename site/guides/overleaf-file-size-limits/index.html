Overleaf file and project size limits, and how to stay under them

By Benjamin Ampel · November 27, 2026

Overleaf caps a project at 2000 files and 7 MB of editable text, and each upload at 50 MB. These limits are the same on the free and paid plans, so upgrading does not raise them. Most projects that hit one can get under it by changing which files Overleaf treats as editable.

Disclosure: I make ModernTex, a Mac LaTeX editor, and it comes up near the end. The numbers below come from Overleaf's plan limits page, its guide to uploading a project and its page on uploading files to a project, all read on November 27, 2026.

The limits

Total project sizeNo enforced limit

The plan limits page lists the same values for free and premium plans. On total size it says "There's no enforced limit," and it recommends staying under 500 MB, or under 100 MB if you use Git or GitHub sync. Over any limit, the uploading page says only: "You must stay within these limits when adding content to your project."

What counts as editable

The 7 MB limit covers editable material, not the whole project. The uploading page says only files "with the most common LaTeX file extensions will be editable," and that "Text files larger than 2 MB cannot be edited online and don't count toward the 7 MB limit." Images and PDFs do not have LaTeX extensions, so by that definition they are not editable and fall outside the 7 MB. A project with 200 MB of figures and 3 MB of .tex and .bib files is within the limit.

Fixes for each limit

  • Over 7 MB editable. Find the large text files. Machine-made ones (data tables, generated .tex from a script, a .bib export of a whole library) are the usual cause. Trim the .bib to the entries you cite, and keep large data files above 2 MB, where Overleaf stores them without counting them. You lose online editing for those files, which is rarely a loss for data.
  • One file over 2 MB that you need to edit. Split it. A long chapter can be several files joined with \input. The plan limits page says to keep a file at 2 MB or less if it should stay editable.
  • An upload over 50 MB. Overleaf's own route is to upload a subset of the files as a zip to create the project, then upload the rest by hand.
  • More than 180 files in one upload. Upload in batches. The uploading page also warns of a short pause after about 200 files in 30 minutes.
  • More than 2000 files. Overleaf gives no advice for this one. What has worked for me is deleting unused figures and old drafts, and combining sets of small images (a grid of subfigures, say) into one PDF per figure.

Size and Git or GitHub sync

The GitHub sync page says sync "won't operate if the total amount of editable (not view-only) content surpasses 7 MB." Both Git and GitHub sync are paid features, so this applies only on a paid plan. If sync stops working on a project that grew, check the editable total before anything else.

When a local copy is simpler

On your own computer the only limit is disk space. If a project is large by design (a thesis with hundreds of figures, a data appendix), keep the full version locally and share a trimmed copy on Overleaf, or skip Overleaf for that project. The MacTeX vs BasicTeX guide covers the TeX install, and the LaTeX editor for Mac comparison covers the editors, free ones included.

Frequently asked questions

What is the Overleaf file size limit?
Overleaf allows 7 MB of editable material per project, 2 MB per editable text file and 50 MB per upload. The total project size has no enforced limit, though Overleaf recommends staying under 500 MB. These values are from its plan limits page, read November 27, 2026.
Does a paid Overleaf plan raise the file limits?
No. Overleaf's plan limits page lists the same file and size limits for the free and premium plans.
Do images count toward Overleaf's 7 MB limit?
Overleaf counts only editable files, which are files with common LaTeX extensions. Images and PDFs are not editable, so by that definition they do not count. Text files over 2 MB also do not count, because Overleaf does not let you edit them online.
How many files can an Overleaf project have?
2000 files per project, on every plan. One upload can hold up to 180 files and 50 MB.
