Templates

LaTeX templates by venue.

A minimal skeleton for each common class, the options that matter, and the mistakes that get papers returned. The IEEEtran, acmart, elsarticle and apa7 skeletons compile as written with a current TeX Live; the NeurIPS one needs that year's style file next to it.

Classes

Pick the class your venue names

The call for papers or the journal's guide for authors names the class. When the venue publishes its own copy of the template, start from that copy; these pages explain what is in it and link to the official source.

IEEEtran

IEEE conference paper

The conference option, author blocks, the IEEEtran bibliography style, and the font embedding that IEEE PDF eXpress checks at camera-ready.

ACM conferences and journals

sigconf for proceedings, acmsmall for journals, and the review and anonymous options for a double-blind submission.

The style file that changes every year, its anonymized default, and the preprint and final options.

Elsevier journals

The frontmatter block, preprint and review modes, and the 1p, 3p and 5p layouts for estimating printed length.

Before you submit

Check the finished paper

Compile the project on a clean machine with LaTeX to PDF, check the .bib file with the BibTeX validator, scan a double-blind copy with Anonymity Check ($2), and get a reviewer's read with Paper Review (from $9). For reference-list formats by venue, see Reference formats.
