ICO to PNG

Get the PNG images out of a favicon, a Windows icon or a cursor (.ico, .cur): the largest size, or every size in a zip, with transparency kept. The icon is read on your device. Nothing is uploaded.

    How it works

    An .ico file holds the same picture at several sizes, often 16, 32, 48 and 256 pixels. Each size is either a PNG, copied out byte for byte, or a Windows bitmap, which the page decodes in a background worker.

    Bitmap sizes carry a second, 1-bit image called the mask that marks the transparent pixels. The page applies it the way Windows does, including for 32-bit sizes whose own transparency is left empty, so icons that look right on Windows look right as PNG.

    When one size is stored at several color depths, the deepest is kept. Every size can come out in one zip, named by its real width and height.

    How to convert ICO to PNG

    1. Pick the sizes. The largest size gives one PNG; Every size gives a zip with one PNG per size.
    2. Add the icons. Drop the .ico or .cur files on the box, click it to choose them, or paste one.
    3. Check the row. Each row shows the size saved, or how many, and notes any size that could not be read.
    4. Download. Download each PNG or zip from its row, or use Download all as .zip.

    Limits

    • Up to 20 MB an icon and 1024 by 1024 pixels a size.
    • 16-bit and compressed bitmap sizes, which are rare, are left out, and the row says so.
    • A cursor's hotspot is not kept in the PNG.

    Questions

    Are my files uploaded?
    No. The page reads each icon with your browser and converts it in a background worker in this tab. There is no server step. The meter under the drop zone counts the bytes the page and its worker send while they work, so you can check this yourself. The only things the page downloads are its own scripts.
    How do I get a site's favicon?
    Most sites serve it at /favicon.ico, so open https://example.com/favicon.ico in your browser and save it. Then drop the file here to get its sizes as PNG.
    Why does my icon have several sizes?
    Windows picks the size that fits where the icon is shown, from 16 pixels in a list to 256 on a large desktop. Choose Every size to get them all, or The largest size for the sharpest one.
    Is transparency kept?
    Yes. PNG sizes keep their own transparency, and bitmap sizes get theirs from the icon's mask, applied the way Windows applies it.
    Is it free?
    Yes. There is no account, no watermark and no limit beyond the sizes above.
