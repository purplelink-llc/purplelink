How to Convert a Research Paper PDF to Clean Markdown for an AI Assistant

By Benjamin Ampel · June 11, 2026

Copying text from a PDF scrambles equations and breaks tables. This guide shows how to use Purplelink's PDF to Structured Data tool to extract clean Markdown that preserves math, tables, and reading order.

Pasting text from a research PDF into an AI assistant's chat window loses equations, scrambles the order of two-column text, and collapses tables into unreadable rows. The PDF to Structured Data tool at Purplelink converts a paper PDF into Markdown that keeps equations as LaTeX, tables intact, and reading order correct.

Steps

  1. Go to purplelink.llc/tools/pdf-structure/. The tool accepts PDF files up to 20 MB. Most journal and arXiv papers fall well within that limit.
  2. Click Choose file and select your PDF.
  1. Click Extract. Processing runs on the server and takes 5 to 30 seconds for most papers. A progress indicator appears while it works.
  2. When extraction finishes, two tabs appear: Markdown and JSON. Select Markdown for pasting into an AI assistant.
  1. Click Copy to copy the full Markdown to your clipboard. Use Download to save a .md file if you plan to reuse the content.
  2. Paste into Claude, ChatGPT, or whichever assistant you use. Equations in the output are LaTeX, for example $$E = mc^2$$ or $$\int_a^b f(x)\,dx$$, which these assistants read and interpret correctly.

What happens under the hood

The tool runs reading-order detection (it works out which block of text follows which) on the PDF. Multi-column text then flows in logical reading sequence, instead of coming out as column one and column two in separate blocks. Tables are identified structurally and rendered as Markdown table syntax. Math formulas are recognized as equation regions and emitted as LaTeX strings (not garbled Unicode characters). Figure captions are detected and kept adjacent to their position in the document. The PDF sits in a temporary folder on our server only while it is converted, then it is deleted. No data is sent to a third-party service. The tool requires a PDF with selectable text. Scanned page images will not extract correctly.

Q&A

What if the paper has a two-column layout?
Reading-order detection handles this. The text flows in logical reading order across both columns, so sentences will not alternate between columns.

When should I use JSON output instead of Markdown?
The JSON output includes element type, content, and bounding-box coordinates for each block. Use it when building a retrieval pipeline or indexing system that needs element-level metadata rather than a flat text stream.

Is this suitable for preprints and arXiv papers?
Yes. Any PDF with selectable text works, including arXiv preprints, published journal articles, and conference papers.
