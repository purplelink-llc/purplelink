WebP to PNG

Convert WebP images to PNG, or to JPG. Your browser decodes and re-encodes each image on your device. PNG keeps transparency; JPG fills it with a color you choose. Nothing is uploaded.

    How it works

    Many sites serve their images as WebP because the files are smaller. Saving one from a browser gives a .webp file that older versions of Word and PowerPoint, some upload forms and pdfLaTeX do not take. pdfLaTeX's \includegraphics reads PNG, JPG and PDF.

    Your browser already reads WebP. This page asks it to decode each file in a background worker, draws the pixels on an off-screen canvas and writes them out as PNG or JPG. No library is downloaded for it.

    PNG is lossless, so it keeps exactly what the WebP shows, including transparent areas. It cannot bring back detail that a lossy WebP already threw away.

    How to convert WebP to PNG

    1. Pick the format. Choose PNG to keep transparency and every pixel, or JPG for a smaller file. For JPG, pick the color that fills transparent areas.
    2. Add the images. Drop the WebP files on the box, click it to choose them, or paste an image you copied.
    3. Wait for each row. Each image is converted in turn and the row shows the new size.
    4. Download. Download each image from its row, or use Download all as .zip.

    Limits

    • Up to 100 MB a file and 200 files at a time.
    • An animated WebP becomes a still image of its first frame.
    • Metadata in the WebP (EXIF, XMP) is not copied over.
    • Colors are converted to sRGB by the browser.
    • Needs Chrome or Edge 69, Firefox 105 or Safari 16.4, or later.

    Questions

    Are my files uploaded?
    No. The page reads each image with your browser and converts it in a background worker in this tab. There is no server step. The meter under the drop zone counts the bytes the page and its worker send while they work, so you can check this yourself. No library is downloaded at all; the browser's own WebP decoder does the work.
    Should I choose PNG or JPG?
    PNG for screenshots, diagrams, logos and anything with transparent areas or sharp edges. JPG for photos, where it gives a much smaller file. JPG has no transparency, so transparent areas are filled with the color you pick, white by default.
    Why is the PNG larger than the WebP?
    WebP compresses better than PNG, and a lossy WebP stores an approximation of the picture. PNG stores every pixel exactly, so the same picture takes more space. Choose JPG if the size matters more than exact pixels.
    What happens to an animated WebP?
    The browser hands over the first frame, and that frame is converted. The page says so on the row.
    Can I use the PNG in a LaTeX paper?
    Yes. pdfLaTeX and XeLaTeX read PNG and JPG with \includegraphics from the graphicx package. Use PNG for plots and diagrams so lines stay crisp.
    Is it free?
    Yes. There is no account, no watermark and no limit beyond the file sizes above.
