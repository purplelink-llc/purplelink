How to run Windows-only research software on an Apple silicon Mac (2026)

Some links on this page are affiliate links. If you buy through one, Purplelink may earn a commission at no extra cost to you. It does not change which products we mention or what we say about them.

By Benjamin Ampel · October 14, 2026

On an M-series Mac, Windows runs in a virtual machine, not through Boot Camp. Most Windows statistics and analysis programs work that way. Programs that need their own drivers, a license dongle or exact timing often do not, so check your program before you buy anything.

Links to Parallels' support and Microsoft pages are sources and earn nothing. The free options (a campus virtual desktop, VMware Fusion and UTM) come first because they cost nothing to try. I did not install any of these tools for this guide. The short answer

Apple's Boot Camp only works on Intel-based Macs (Apple: Boot Camp). On an Apple silicon Mac, you run Windows 11 for Arm inside a virtual machine (a program that runs a second operating system in a window). Windows for Arm then emulates ordinary x64 Windows programs. Microsoft states the limit plainly: emulation covers user-mode code and not drivers, so any kernel-mode part must be built for Arm (Microsoft: How emulation works on Arm). That one rule explains most of what works and what does not.

Steps

  1. Check for a Mac or browser version first. Several programs researchers assume are Windows-only now run natively on a Mac, or have a browser version. The table below lists common ones.
  2. Ask your university about a virtual desktop. Many campuses stream Windows software to a Mac through Citrix, AppsAnywhere or a similar service, at no cost to you. Cambridge, for example, offers a virtual Windows desktop to all staff and students (University of Cambridge).
  3. Check your program's own statement on virtual machines. Search the vendor's support pages for "Parallels", "virtual machine" or "Apple silicon". Some vendors say outright that they do not support it.
  4. Get a Windows license. Look in your university's software store before buying one. Parallels recommends Windows 11 Pro or Enterprise, and each virtual machine needs its own license (Parallels: Windows 11 on Arm).
  5. Pick a virtual machine app and try it before paying. Parallels offers a 30-day money-back guarantee on direct purchases. VMware Fusion and UTM cost nothing to try.
  6. Install your program and test the part you depend on. Run a real analysis, open a real project file and print or export, before you move your work across.

What usually does not work

  • Programs with their own drivers. Emulation does not cover drivers, so instrument software, some USB license dongles and copy protection that installs a driver fail unless the vendor ships an Arm version.
  • Timing-critical experiments. A virtual machine adds delay that you cannot control. E-Prime's vendor says so directly.
  • Windows features that need nested virtualization. Parallels lists Windows Sandbox, virtualization-based security and some WSL and emulator setups as unsupported.
  • Some graphics-heavy programs. Parallels notes limits with some DirectX 12 programs, and Esri lists GPU limits for ArcGIS Pro.

How much Mac you need

Parallels recommends 16 GB of memory or more, with 8 GB as the minimum, and at least 16 GB of free disk space for Windows (Parallels requirements). In practice, Windows, Office and one large statistics package take far more than 16 GB. On an 8 GB Mac, expect both systems to slow down while the virtual machine runs.

Frequently asked

Can I still use Boot Camp?

Not on an Apple silicon Mac. Apple says Boot Camp is for Intel-based Macs only. On an M-series Mac, Windows runs in a virtual machine instead.

Do I need to buy Windows as well as Parallels?

Yes. Parallels, VMware Fusion and UTM do not include a Windows license. Check your university's software store first, since many campus agreements include Windows. CrossOver is the exception: it runs some Windows programs without Windows at all.

Will my Windows statistics program run on Windows for Arm?

Usually, if it is an ordinary desktop program. Windows 11 for Arm emulates x64 programs, but emulation does not cover drivers. Software that needs its own driver, a USB license dongle or precise hardware timing is where it fails.

How much memory does my Mac need?

Parallels recommends 16 GB or more and lists 8 GB as the minimum. Windows also needs at least 16 GB of disk space, and in practice far more once your software and data are on it.

Is VMware Fusion really free?

Broadcom made Fusion Pro free for personal use in May 2024. Whether university research counts as personal use is a question for Broadcom's current license terms or your IT office, so check before relying on it for funded work.
