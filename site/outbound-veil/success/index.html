Installing

Open the disk image

Drag Outbound Veil to Applications, then open it from there. The app is signed by Purplelink LLC and needs macOS 14 or later.

Allow Accessibility

On first launch macOS asks for Accessibility permission. Outbound Veil needs it to read the text field you are typing in. Input Monitoring is asked for only if you turn on send hold.

It updates itself

The app checks for new versions and offers to install them in place. You can also choose Check for Updates from its menu.
