Two things nobody enjoys writing by hand

A TikZ diagram and a results table are both capable LaTeX. However, neither is a pleasant place to start from a blank line and a syntax reference. ModernTex builds both visually and drops in the real source underneath. Nothing is hidden, and you could have typed all of it yourself.

TikZ Designer

Drag boxes and arrows into place, pick colors from a swatch, resize by the corner, connect two shapes by dragging between them. Start from a flowchart, pipeline, state machine, or tree preset, or a blank canvas. Reopen an existing diagram from the Figures menu to keep editing it instead of redrawing it.

Table Editor

Paste a range straight from Excel or Google Sheets and it lands in the right cells. The table grows if the data is bigger, and the rest stays untouched if it is smaller. Return moves down a row, ⌥Return breaks a line inside a cell, and dragging a column edge resizes it, as in a spreadsheet. Underneath is booktabs-style tabular.

Features

What the manuscript needs

Multi-file manuscript navigation

ModernTex detects the root file and shows a structured sidebar. Jump between chapters, sections, and bibliography files without losing your place.

Three compile modes

Fast, Live, and Full compile modes trade speed for completeness. Live mode keeps the PDF in sync as you type. Full mode does the complete pass before submission.

Synchronized PDF preview

Forward and inverse search: click the source to jump to the PDF, click the PDF to jump to the source. Side by side, always in sync.

Citation management

BibTeX autocomplete that searches your bibliography by author, title, or key, not only the keys you have already cited. Suggestions come from your .bib files as you type a citation.

Plain-language error diagnostics

LaTeX error messages are terse. ModernTex translates them into plain explanations with suggested fixes, so you spend less time decoding errors.

Submission readiness checks

Automatically check anonymization, page limits, required sections, and submission packaging before you hit send, so formatting problems are caught before a journal returns the paper.

Version snapshots

Take a snapshot at any point, such as before a major revision, after peer review, or before resubmission. Compare any two snapshots in a diff.

Live TikZ figure editor

Build flowcharts and diagrams by dragging boxes and drawing connections on a canvas. ModernTex generates the TikZ code as you go. Insert it at your cursor when it is ready.

Table editor

Paste a range from Excel or Google Sheets straight into the right cells. Resize columns by dragging, set a table-wide font, and generate clean booktabs-style LaTeX underneath.

Native macOS app

Built in Swift for macOS 14+. It has native dark and light mode, system fonts, and standard keyboard shortcuts.

Plain-language errors

From a cryptic error to a fix

LaTeX reports a mistake in its own terms and leaves you to work out what it means. ModernTex reads the error and says what went wrong in plain language, with a suggested fix.

What LaTeX prints

! Undefined control sequence.
l.42 As shown by \citeauthr
                           {smith2024}, the effect holds.

What ModernTex tells you

LaTeX does not recognize the command \citeauthr on line 42. This is usually a misspelled command, or a package that defines it is not loaded.

Suggested fix

- Remove: \citeauthr{smith2024}
+ Add: \citeauthor{smith2024}

This is an illustrative example, not a capture from the app. The wording varies with the error.

Switching

Coming from another editor

From Overleaf

Bring the project over as a zip, or as a Git clone if your Overleaf plan has Git. It builds on your Mac, so there is no compile timeout. There is no real-time co-editing, so a co-author can stay in Overleaf. How that works, and the comparison.

From TeXShop or TeXstudio

Open the same folder; there is nothing to convert. What changes is plain-language errors, bibliography search by author or title, and submission checks. It is Mac only. The comparison.

From VS Code

VS Code with LaTeX Workshop is free and very configurable. ModernTex is for people who want build, PDF, bibliography and submission checks to work without setting anything up. If you like building your own setup, stay where you are. What I tested.

A co-author who stays in Overleaf

ModernTex can keep a local copy of an Overleaf project through Overleaf's Git integration. In Overleaf, open the project, choose Menu, then Git, and copy the address, which looks like https://git.overleaf.com/ followed by the project id. Create a Git authentication token in your Overleaf account settings. In ModernTex, open Overleaf sync (Command-Shift-E), paste the address, and enter the token as the password. Pull, edit and build on your Mac, then Push to send your changes back to the project. Your co-author sees them in Overleaf.

Two limits. Overleaf's Git integration is a paid Overleaf feature: it is available when the project's owner has a paid plan (Overleaf's Git documentation, read October 15, 2026). The zip route works on every plan. And it is not real-time: you and your co-author each work on a copy, and Overleaf advises against mixing Git pushes with its track changes and comments, because a push can disrupt them.

For two Macs, or a co-author who uses GitHub or GitLab, Get Changes and Send Changes work with any plain Git remote, and Changes Since Last Sync builds a PDF with your edits marked. Step by step: Move an Overleaf project to a local Mac editor with Git.

ModernTex is a native macOS app designed specifically for the academic manuscript workflow. It is not a web app and not a general-purpose code editor. It combines multi-file manuscript navigation, synchronized PDF preview, BibTeX autocomplete that searches by author or title, plain-language error diagnostics, and submission-readiness checks. Why not just use a free editor like TeXstudio?
TeXstudio is free, cross-platform, and already parses compile errors into a readable list, so it is a legitimate choice, especially if you also work on Windows or Linux. ModernTex is narrower on purpose. It is Mac only and built around the manuscript workflow. TeXstudio does not do three things: BibTeX autocomplete that searches your whole .bib by author or title rather than just the keys already cited in the file, submission-readiness checks for what journals actually reject on, and an anonymized export for double-blind review. If none of those matter to you, TeXstudio is a good free option.
Does ModernTex support multi-file projects?
Yes. ModernTex has built-in multi-file manuscript navigation with root file detection and a structured sidebar for jumping between chapters, sections, and bibliography files without losing context.
Does it work for a dissertation?
Yes. A dissertation is a multi-file project like any other: open the folder and ModernTex finds the root file and lists the chapters in the sidebar. The bibliography can be BibTeX or biblatex with biber (a switch in the compile profile), reading any .bib in the project, including one exported from Zotero. A class file your university supplies goes in the project folder, where the compile picks it up and the submission export includes it. A generic thesis template is bundled.
Will I have to pay again for a new version?
No. Every update to ModernTex is included in the $19.99, forever, including future major versions. There is no upgrade fee.
Does ModernTex work offline?
Yes. Your files are ordinary files on your Mac and the compile runs on your Mac, so there is no server and no compile timeout. You need a TeX distribution, MacTeX or TinyTeX, and ModernTex can install TinyTeX for you. The license key is checked inside the app with no server involved. The optional AI features run on Apple Intelligence on your Mac, or on your own Claude or OpenAI account, which needs a connection.
What if I stop using ModernTex?
Your manuscripts stay ordinary .tex, .bib and image files in a folder on your disk, so TeXShop, TeXstudio or any other LaTeX editor can open them. There is no account to close and no subscription to cancel. If the trial ends before you buy, the window shows a notice and a Buy button, and your files are not touched.
What if ModernTex stops being updated?
Your manuscripts are ordinary .tex and .bib files, so nothing is locked in. The license key is checked inside the app with an offline signature check and no server, so a key you have keeps working without any Purplelink service, and the copy you installed keeps running. ModernTex is made by one person, and I do not promise a support period. The refund window is 14 days.
What does Fix with AI send?
Only when you click it on a build error. By default it runs on Apple Intelligence on your Mac and sends nothing. If you choose a Claude or OpenAI account instead, the app asks for your consent first, and then sends the lines around the error, some surrounding context and the document preamble to that provider. The repair is shown as a diff, and nothing changes until you accept it.
Does it work with my journal's or university's class file?
Any class you can compile with LaTeX works: put the class file in the project folder. ModernTex also bundles starter templates for several information systems journals, computer science conferences and a generic thesis. The free starters on this site for ACM, IEEE, Elsevier, APA 7 and the academic CV each compiled with TinyTeX and latexmk when I tested them on October 15, 2026, after the publisher class was installed with tlmgr. The NeurIPS starter needs the current year's style file from the conference, so I make no compile claim for it.
