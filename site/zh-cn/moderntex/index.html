源码与 PDF，始终同步

一个窗口里有项目、源码，以及由它生成的 PDF。

打开文件夹

ModernTex 会找到主文件，并在侧边栏列出项目的章节、图片和 .bib 文件。你可以在它们之间跳转，不会丢掉当前位置。

一边写，一边编译

在 Live 模式下，PDF 随着输入重新生成。窗口里的示例在 Mac 上用了半秒编译完，没有用到服务器。

点一下，双向跳转

点击源码中的一行，就能在 PDF 里找到对应位置；点击 PDF，就会跳到生成它的那一行。

两件没人愿意手写的事

TikZ 图和结果表，通常从语法手册和一行空白开始。ModernTex 让你用可视化方式做出这两样，并把真实的源码放在下面。没有任何东西被藏起来，你也完全可以自己敲出同样的代码。

TikZ 编辑器

把方框和箭头拖到位置上，从色板里选颜色，拖动角落调整大小，从一个图形拖到另一个图形就能把两者连起来。可以从流程图、流水线、状态机或树形的预设开始，也可以用空白画布。已有的图可以从 Figures 菜单重新打开继续编辑，不必重画。

表格编辑器

从 Excel 或 Google 表格复制一个区域，直接粘贴，内容会落在正确的单元格里。数据更大时表格会扩展，更小时其余部分保持不变。Return 移到下一行，⌥Return 在单元格内换行，拖动列的边缘可以调整列宽，和电子表格一样。底层是 booktabs 风格的 tabular。

你的稿件仍然是 Mac 上一个由普通 .tex 和 .bib 文件组成的文件夹。 编译在你的 Mac 上进行，所以没有编译超时。 不用注册账号，也没有需要取消的订阅。

稿件需要什么

多文件稿件导航

ModernTex 会识别主文件，并显示有层次的侧边栏。在章节、小节和参考文献文件之间跳转，不会丢掉位置。

三种编译模式

Fast、Live 和 Full 用速度换完整度。Live 在输入时保持 PDF 最新，Full 在提交前完整跑一遍。

同步的 PDF 预览

支持正向和反向搜索：点击源码跳到 PDF，点击 PDF 跳到源码。并排显示，始终同步。

文献管理

BibTeX 补全按作者、标题或键搜索整个文献库，而不只是已经引用过的键。输入引用时，建议来自你的 .bib 文件。

投稿前检查

发送前检查匿名化、页数限制、必需的章节和投稿打包，让格式问题在期刊退稿之前就被发现。

版本快照

可以随时拍一份快照，比如大修之前、审稿之后或再次投稿之前。任意两份快照可以用 diff 对比。

版本 2 的新功能

分栏编辑器、多光标、全项目查找、Vim 模式和可视化公式编辑器，还有 HTML 与 EPUB 导出、knitr 和 PythonTeX、Zotero、终端、远程项目、宏、插件和自定义主题。

原生 macOS 应用

需要 macOS 14 或更高版本，跟随你的浅色或深色设置，使用 Mac 的标准快捷键。

从看不懂的报错到修复

LaTeX 用自己的话报告错误，让你自己去理解。ModernTex 把错误翻译成日常语言，并给出修改建议。

LaTeX 的输出

! Undefined control sequence.
l.42 As shown by \citeauthr
                           {smith2024}, the effect holds.

ModernTex 的解释

LaTeX 不认识第 42 行的命令 \citeauthr。常见原因是命令拼写错误，或者定义它的宏包没有加载。

建议的修改

- 删除：\citeauthr{smith2024}
+ 添加：\citeauthor{smith2024}

这是一个演示用的例子，不是应用的截屏。具体措辞会随错误而变。

用于中文论文

写中文论文时常遇到的几件事，以及 ModernTex 目前确实能做到的部分。

XeLaTeX 与 ctex

编译使用你本机的 TeX。XeLaTeX 和 LuaLaTeX 的文档可以直接编译。要固定引擎，在文件开头写一行 % !TEX program = xelatex。ctex（\documentclass{ctexart} 或 \usepackage[UTF8]{ctex}）在 Mac 上会使用系统自带的中文字体，我在测试中没有额外设置字体。

GB/T 7714 参考文献

Full 编译在 XeLaTeX 和 LuaLaTeX 下也会运行 biber，所以 biblatex-gb7714-2015 这类需要 biber 的样式可以使用。在编译配置里可以在 BibTeX 和 biblatex（biber）之间切换。写法见指南。

学校的论文模板

能用 LaTeX 编译的类文件都可以用：把学校的类文件放进项目文件夹。把类文件放在 Styles 文件夹里的模板也能编译。thuthesis 这类学校模板通常依赖 XeLaTeX，我没有逐个测试各学校的模板，需要的宏包可以用 tlmgr 安装。

界面是英文，数据留在 Mac 上

应用界面目前是英文。稿件在你的 Mac 上编辑和编译，没有云同步，也不收集数据。可选的 AI 功能运行在 Mac 上的 Apple Intelligence，或你自己的 Claude 或 OpenAI 账号上，使用前会先征得你的同意。

不太适合的情况： 几位合作者需要同时在同一份文档里输入（那份稿件请继续用 Overleaf），你在 Windows、Linux 或 iPad 上工作，或者不想在 Mac 上装 TeX 发行版。ModernTex 在 2026 年 9 月才首次发布，所以不如 TeXShop 或 Texifier 的历史长。其他选择见 Mac 上 LaTeX 编辑器的对比（英文）。

从其他编辑器迁移

从 Overleaf 迁移

把项目下载成 zip，或者如果你的 Overleaf 套餐带 Git，就用 Git 克隆。编译在你的 Mac 上进行，所以没有超时。没有实时协同编辑，合作者可以继续留在 Overleaf。

从 TeXShop 或 TeXstudio 迁移

打开同一个文件夹即可，不需要转换。变化的是：用日常语言解释的错误、按作者或标题搜索文献，以及投稿前检查。ModernTex 只支持 Mac。

从 VS Code 迁移

装了 LaTeX Workshop 的 VS Code 免费，而且可配置性很强。ModernTex 面向的是希望编译、PDF、文献和投稿检查开箱即用的人。如果你喜欢自己搭环境，就继续用它。

ModernTex 能编译中文 LaTeX 文档吗？
可以。编译使用你本机的 TeX，XeLaTeX 和 LuaLaTeX 的中文文档可以直接编译。在文件开头写 % !TEX program = xelatex 即可固定引擎。完整的写法见在 Mac 上用 XeLaTeX 和 ctex 写中文论文。

需要哪个版本的 macOS？
ModernTex 需要 macOS 14 (Sonoma) 或更高版本。
能把 Overleaf 上的项目迁过来吗？
可以。把项目下载成 zip，或者用 Overleaf 的 Git 集成克隆（Git 需要付费的 Overleaf 套餐，zip 在所有套餐下都能用），然后在 ModernTex 里打开这个文件夹。文件仍然是普通的 .tex、.bib 和图片文件，你随时可以传回 Overleaf。
为什么不直接用 TeXstudio 这样的免费编辑器？
TeXstudio 免费、跨平台，而且已经会把编译错误整理成易读的列表，是一个正当的选择，尤其当你也在 Windows 或 Linux 上工作。ModernTex 有意做得更窄：只支持 Mac，围绕稿件的工作流设计。TeXstudio 没有三样东西：按作者或标题搜索整个 .bib 的 BibTeX 补全、针对期刊实际会退稿的问题的投稿前检查，以及用于双盲审稿的匿名导出。如果这些对你都不重要，TeXstudio 是个不错的免费选择。
适合写学位论文吗？
适合。学位论文就是一个普通的多文件项目：打开文件夹，ModernTex 会找到主文件，并在侧边栏列出各章。参考文献可以用 BibTeX，也可以用 biber 的 biblatex（在编译配置里切换），能读取项目里的任何 .bib，包括从 Zotero 导出的。学校提供的类文件放进项目文件夹，编译会用到它，投稿导出也会带上它。应用内置一个通用的学位论文模板（英文）。

ModernTex 能离线使用吗？
能。你的文件在你的 Mac 上，编译也在你的 Mac 上进行，所以没有服务器，也没有编译超时。你需要一个 TeX 发行版，MacTeX 或 TinyTeX，ModernTex 可以替你安装 TinyTeX。许可证密钥在应用内验证，不需要服务器。可选的 AI 功能运行在 Mac 上的 Apple Intelligence，或你自己的 Claude 或 OpenAI 账号上，后者需要联网。
如果我不再使用 ModernTex 会怎样？

Fix with AI 会发送什么？
