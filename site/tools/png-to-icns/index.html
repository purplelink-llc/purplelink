PNG to ICNS

Turn a PNG, JPG or WebP into a macOS .icns file with the ten icon entries Finder and the Dock use, from 16 to 1024 pixels. The file is built in your browser. Start from a square picture of 1024 by 1024 pixels for a sharp icon. Nothing is uploaded.

    How it works

    An .icns file is a container: a short header, then one PNG for each icon size and pixel density. Finder picks the one that fits, from 16 pixels in a list view to 1024 pixels on a Retina screen.

    This page draws each size from your picture, halving it step by step so the small sizes stay clean, and writes the container byte by byte. It then reads the file back and checks every entry before it offers the download.

    Tick Include an .iconset folder to also get the PNGs named the way Apple's iconutil expects, from icon_16x16.png to icon_512x512@2x.png. Running iconutil -c icns on that folder builds the same kind of file on your own Mac.

    How to convert PNG to ICNS

    1. Start from a square picture. Use a PNG of 1024 by 1024 pixels with a transparent background. Smaller pictures work but look soft at the large sizes.
    2. Add it. Drop the picture on the box, or click it to choose it.
    3. Download the .icns. Download the file from its row. Tick Include an .iconset folder first if you want the separate PNGs too.
    4. Use it. In Finder, select a folder or app, choose File, Get Info, and drag the .icns file onto the small icon at the top left of the window.

    Limits

    • A picture that is not square is centered, with transparent space around it.
    • Every size is drawn from the same picture. Icon designers often redraw 16 and 32 pixels by hand so they read at that size.
    • SVG is not accepted. Export a 1024 pixel PNG from your drawing app first.
    • macOS 10.8 and later read all ten entry types.
    • Needs Chrome or Edge 69, Firefox 105 or Safari 16.4, or later.

    Questions

    Are my files uploaded?
    No. The page reads each picture with your browser and converts it in a background worker in this tab. There is no server step. The meter under the drop zone counts the bytes the page and its worker send while they work, so you can check this yourself. No library is downloaded; the browser draws the sizes and this page writes the file.
    Which sizes are in the file?
    16, 32, 128, 256 and 512 pixels at 1x, and the same five at 2x (32, 64, 256, 512 and 1024 pixels), the same ten pictures an .iconset folder holds. They are stored as the entries icp4, icp5, ic07, ic08 and ic09, then ic11, ic12, ic13, ic14 and ic10. Each is a PNG with transparency.
    Can I use it in an Xcode project?
    Xcode builds the app icon from the PNGs in an asset catalog. Tick Include an .iconset folder and drag those PNGs into the AppIcon set. The .icns file itself is what an app built without Xcode, or a script, points to with CFBundleIconFile in Info.plist.
    How do I change a folder's icon?
    Select the folder in Finder and choose File, Get Info. Drag the .icns file onto the small icon at the top left of the Info window. To undo it, click that small icon and press Delete.
    Why does my icon look blurry?
    Most often the source picture was smaller than 1024 pixels, so the larger sizes were enlarged. The page warns when that happens. Very thin lines can also fade at 16 and 32 pixels, which is why designers simplify the small sizes.
