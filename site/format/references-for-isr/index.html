References for ISR

Information Systems Research accepts LaTeX or Word manuscripts. Paste your references below and convert them to BibTeX. Everything runs in your browser.

Converted output

Your references never leave your browser. There's no upload and nothing is stored.

What ISR expects

  • Manuscript format: LaTeX or Word
  • Template: INFORMS journal LaTeX style files (includes a BibTeX .bst matching INFORMS reference format)
  • Citation style: Author-year (e.g. “(Norman 1977)”), with references listed alphabetically, per the INFORMS house style guide.

ISR is one of the few venues here that officially supports both paths. INFORMS publishes a BibTeX style file for LaTeX authors and a separate EndNote style (“Inf Syst Res.ens”) for Word/reference-manager authors.

Two routes to an ISR reference list

INFORMS supports two ways of producing a reference list that matches its house style, and the one you use follows from how you write the manuscript.

  • LaTeX. Keep your references in a .bib file and use the INFORMS journal LaTeX style files. They include a BibTeX style, so the author-year citations and the alphabetical list are built for you. You download the files from the INFORMS author portal linked under “Where this comes from” below.
  • Word. Use the INFORMS EndNote style, named “Inf Syst Res.ens”, in EndNote or another reference manager that can read it. Your library supplies the data and the style does the formatting.

Either way, the formatting is done by the INFORMS style, not by this page. What this page’s converter does is move reference data between BibTeX, RIS and EndNote, which is useful when your references live in one format and the route you chose needs another.

A worked example

Say you collected references in a reference manager and need a .bib file for the LaTeX route. Export them as RIS or EndNote, paste them into the box above, leave “From” on auto-detect and keep “To” on BibTeX. Going the other way, this entry in BibTeX:

@article{smith2020,
  title   = {On Things},
  author  = {Smith, Jane and Doe, John},
  journal = {Journal of Examples},
  year    = {2020},
  volume  = {12},
  pages   = {3--14},
  doi     = {10.1000/example}
}

converts to EndNote as the tagged lines below, one tag per field, which a reference manager can import for the Word route.

%0 Journal Article
%A Smith, Jane
%A Doe, John
%T On Things
%D 2020
%J Journal of Examples
%V 12
%P 3-14
%R 10.1000/example

What the converter keeps and what it leaves out

The conversion runs in your browser, so nothing is uploaded. It reads each entry into a fixed set of fields: type, title, authors, year, journal or book title, volume, issue, pages, publisher, DOI, URL, abstract and keywords. It writes those fields in the format you choose and drops anything else, such as a note or an editor field. It also builds a new BibTeX key from the first author’s surname and the year, so smith2020 may differ from the key you used in your text. After converting, compare the keys with your \cite commands, and check the result against your source list before you submit.

Frequently asked

What LaTeX template does ISR use?

INFORMS journal LaTeX style files (includes a BibTeX .bst matching INFORMS reference format)

What citation style does ISR use?

Author-year (e.g. “(Norman 1977)”), with references listed alphabetically, per the INFORMS house style guide.

Can I submit to ISR in Word?

Yes. ISR accepts LaTeX or Word manuscripts. Word authors can use the INFORMS EndNote style, “Inf Syst Res.ens”, to format the reference list.

Which should I use, the BibTeX style or the EndNote style?

Use the one that matches how you write. LaTeX authors use the BibTeX style that comes with the INFORMS LaTeX files. Authors working in Word and a reference manager use the EndNote style. Do not mix the two in one manuscript.

Does this page format my references in ISR style?

No. It converts reference data between BibTeX, RIS and EndNote. The ISR formatting, author-year citations with an alphabetical list, comes from the INFORMS style you apply afterwards.

Where do I confirm the current ISR rules?

On the INFORMS author portal, linked in the sources section at the bottom of this page. Instructions change between submission cycles, so read the current version before you submit.
