# Part A: Graduate offices and library LaTeX guides (ModernTex outreach targets)

Access date for all rows: 2026-10-07. Read-only research; nothing was sent or submitted.

Method note: pages were fetched with WebFetch, which returns a model-written summary of each page, not raw HTML. For the rows marked "verbatim" in the contact column, I made a second fetch asking for the exact sentence or mailto link, and the address appeared in that text. Other addresses appeared in one summary only; re-open the page and copy the address from the page before sending anything. No address below was constructed or guessed.

Priority: 1 = best fit and a role/office address; 2 = usable; 3 = weak fit, policy-limited, or personal guide-owner address.

## Suggested first batch (role address, editor gap, current page)

1. Georgia Tech thesis@grad.gatech.edu (lists only Texmaker and MiKTeX; says it does no technical support, so frame it as a resource suggestion).
2. UW-Madison libraries@wisc.edu (guide has no TeXShop and no Mac-native editor).
3. University of Akron librarians@uakron2.libanswers.com (guide names no editors).
4. St. Mary's College ask@smcm.libanswers.com (role address; guide lists TeXShop and Texmaker for Mac).
5. Purdue thesishelp@purdue.edu (only a loosely related angle: offline desktop LaTeX for controlled-content theses; the office names only desktop Word, so ask rather than pitch).

Caveat on frame: several graduate offices explicitly say they do not support LaTeX (Georgia Tech, Duke, Georgetown, UTSA, UCSD). Those statements apply to technical support, not to resource lists, but expect "we do not endorse software" replies.
