Springer Nature journal template (sn-jnl)

By Benjamin Ampel · November 19, 2026

Springer Nature uses one general LaTeX template, sn-jnl, for its journals. This page has a skeleton, the class options that set the reference style, and the reasons a submission that builds on your Mac fails on Springer's system.

Springer Nature publishes a general LaTeX template for its journals. Its class is sn-jnl, and the current package is the December 2024 version. The same template is on Overleaf. CTAN does not list an sn-jnl package, so a standard TeX Live install does not include the class. Download it from Springer Nature or Overleaf and keep it in your project folder.

The template is not a full guide for authors. Check the journal's own instructions for length, structure and reference rules.

Minimal skeleton

The structure follows the sample file in Springer Nature's package. Save your references as references.bib in the same folder as main.tex, sn-jnl.cls and the .bst file for your reference style. Build with pdfLaTeX, then BibTeX, then pdfLaTeX twice.

Download the starter (.zip) main.tex, references.bib and a README. It does not include sn-jnl.cls or the .bst files: get them from Springer Nature or the Overleaf template. Writing on a Mac? Open the folder in ModernTex.

\documentclass[pdflatex,sn-mathphys-num]{sn-jnl}

\usepackage{graphicx}
\usepackage{amsmath,amssymb,amsfonts}
\usepackage{booktabs}

\begin{document}

\title[Article Title]{Article Title}

\author*[1]{\fnm{First} \sur{Author}}\email{first@example.edu}
\author[2]{\fnm{Second} \sur{Author}}\email{second@example.edu}

\affil*[1]{\orgdiv{Department}, \orgname{University},
  \orgaddress{\street{Street}, \city{City}, \postcode{00000},
  \state{State}, \country{Country}}}
\affil[2]{\orgdiv{Department}, \orgname{Company},
  \orgaddress{\street{Street}, \city{City}, \postcode{00000},
  \state{State}, \country{Country}}}

\abstract{One paragraph that states the problem, the method
and the result.}

\keywords{first keyword, second keyword, third keyword}

\maketitle

\section{Introduction}\label{sec1}
Text with a citation \cite{example}.

\section{Conclusion}\label{sec2}
Summary.

\bibliography{references}

\end{document}

There is no \bibliographystyle line. The reference-style option in \documentclass picks the style.

Class options for the reference style

You choose the reference style with a class option, and each option has a matching .bst file in Springer Nature's package. These names come from the sample file sn-article.tex and the file list in the December 2024 template package, read on 2026-11-19. The package also includes a user manual with the full details. Use one style option per document.

  • sn-basic: the basic Springer Nature reference style.
  • sn-mathphys-num and sn-mathphys-ay: math and physical sciences, numbered or author-year.
  • sn-aps: American Physical Society.
  • sn-vancouver-num and sn-vancouver-ay: Vancouver, numbered or author-year.
  • sn-apa: APA. Its style file is sn-apacite.bst.
  • sn-chicago: Chicago-based, for the humanities.
  • sn-nature: for submissions to Nature Portfolio journals. See Nature reference format.

Other class options in the sample file: pdflatex, referee for double line spacing, and lineno for line numbers in the margin. The sample file says sn-basic and sn-chicago can switch between name-date and numbered citations. The user manual explains how.

Why a build that works on your Mac fails on upload

  • Springer Nature builds with pdfLaTeX. Snapp, its article processing platform, compiles with pdfLaTeX and takes a .zip. Keep the pdflatex option in \documentclass. Use \usepackage{graphicx} without the dvips option.
  • The TeX Live version is older than yours. Snapp uses TeX Live 2021. Editorial Manager uses TeX Live 2018, and eJP uses TeX Live 2017. A package that only exists in a newer release will fail there.
  • One flat folder. Springer Nature says figures can go missing when files sit in subfolders. Put every file in one directory and write \includegraphics{fig1.pdf}, not a path. Springer Nature's package keeps its .bst files in a bst folder. Move the one you use next to main.tex.
  • The class and style files travel with the project. The class is not part of a standard TeX Live install. Put sn-jnl.cls and the .bst file in the folder you upload. In Editorial Manager a .bst file must go up with the bibliography. In eJP, upload the .bib and .bst as Related Manuscript Files.
  • Paste the .bbl into the .tex. For Editorial Manager and eJP, Springer Nature calls this the most reliable method. Build once, open main.bbl, copy its contents into main.tex in place of the \bibliography line, and delete that line. Upload a .bbl file separately only if the main file imports it.
  • Citations print as ??. Springer Nature says this usually means the bibliography file is missing or corrupted. Check that the .bib, .bst or .bbl is uploaded and declared.
  • One .tex file. The sample file asks you not to use \input to include other .tex files.
  • Custom fonts and accents. Springer Nature does not support custom fonts. Write diacritics as TeX code, for example \"a.

For the zip itself, see how to package LaTeX source for a journal.

  • Compile LaTeX to PDF online (free). Upload the .tex file or a .zip of the project and get the PDF back, compiled with pdfLaTeX or XeLaTeX. It is useful for a clean build on a machine that is not yours. Include sn-jnl.cls and the .bst file in the zip.
  • BibTeX validator (free): flags missing required fields, duplicate keys, dead DOIs and entries that do not match a real paper. It runs in the browser.

  • Paper Review (from $14): seven AI reviewers read the manuscript for methods, statistics and the editor's view, and every reference is checked against CrossRef.
  • Word counter (free): word counts per section, with and without references, for abstract and length limits.
