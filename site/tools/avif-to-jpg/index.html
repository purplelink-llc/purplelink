AVIF to JPG

Convert AVIF images to JPG, or to PNG. Your browser decodes each image and writes the new file on your device. PNG keeps transparency; JPG fills it with a color you choose. Nothing is uploaded.

    Files are read and converted in this tab, in a background worker. The only requests the page makes are for its own scripts. Your files are never sent anywhere.

    How it works

    AVIF is a newer image format that many sites now serve because its files are small. Saving an image from such a site gives a .avif file, which older Windows and Office versions, many upload forms and LaTeX do not open.

    Current browsers read AVIF. This page asks yours to decode each file in a background worker, draws the pixels on an off-screen canvas and writes them out as JPG or PNG. No library is downloaded for it.

    JPG is the smaller file and opens everywhere. PNG keeps every decoded pixel and any transparent areas.

    How to convert AVIF to JPG

    1. Pick the format. Choose JPG for photos, or PNG to keep transparency and every pixel. For JPG, pick the quality and the color that fills transparent areas.
    2. Add the images. Drop the AVIF files on the box, click it to choose them, or paste an image you copied.
    3. Wait for each row. Each image is converted in turn and the row shows the new size.
    4. Download. Download each image from its row, or use Download all as .zip.

    Limits

    • Up to 100 MB a file and 200 files at a time.
    • The browser does the decoding, so it has to read AVIF: Chrome and Edge 85, Firefox 93, or Safari 16.4 on macOS 13 or iOS 16 and later.
    • An animated AVIF becomes a still image of its first frame.
    • HDR and 10-bit AVIF images are written as ordinary 8-bit sRGB, so very bright highlights are flattened.
    • Metadata in the AVIF (EXIF, XMP) is not copied over.

    Questions

    Are my files uploaded?
    No. The page reads each image with your browser and converts it in a background worker in this tab. There is no server step. The meter under the drop zone counts the bytes the page and its worker send while they work, so you can check this yourself. No library is downloaded at all; the browser's own AVIF decoder does the work.
    Why won't my browser read the AVIF file?
    Safari reads AVIF only from macOS 13 Ventura and iOS 16 onward. On an older Mac, open this page in Chrome, Edge or Firefox instead. If a current browser also fails, the file is likely damaged or cut short.
    Should I choose JPG or PNG?
    JPG for photos: a much smaller file that opens everywhere, and at the default quality of 92 it looks the same to most eyes. PNG for screenshots, logos and anything with transparent areas or sharp edges.
    Why is the JPG larger than the AVIF?
    AVIF compresses better than JPG, so the same picture takes more space as a JPG. Lower the JPEG quality to 80 for a smaller file with little visible change.
    Can I use the result in a LaTeX paper or a Word document?
    Yes. pdfLaTeX reads JPG and PNG with \includegraphics, and every version of Word, PowerPoint and Google Docs takes both.
    Is it free?
    Yes. There is no account, no watermark and no limit beyond the file sizes above.
