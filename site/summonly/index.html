How it works

It indexes in the background

Summonly reads file names, and the start of text files, PDFs and Office documents, in the folders you choose, and keeps a small searchable index on your Mac. If you turn on question search it also reads whole documents. macOS tells it when files change, so the index stays current.

You open it and type

Press Option-Space. Results appear as you type. A quick answer comes first if the text is a sum, a unit conversion or one of the quick tools. Files and apps follow, ranked by how well the name matches and how often you open them.

You act on a result

Return opens it. Command-Return shows it in Finder. Option-Return copies its path. A calculation, snippet or clipboard item is copied.

What it does

FindsFile and folder names, apps, and the start of text, code and Markdown files, RTF files and the first pages of PDFs. The text of Word, Excel, PowerPoint and OpenDocument files is read too. Pages and Keynote files are found by name only.
AbbreviationsType vsc for Visual Studio Code, or te for TextEdit. Summonly matches the first letters of an app's words. The start of a name written as one word works too: oned finds OneDrive.
Filterskind:pdf, ext:docx, in:Documents, modified:today, modified:week, after:2026-01-01 and before:2026-03-01, name:budget (names only) and size:>5mb or size:<200kb. Put words in quotes to match them side by side. Put a minus sign before a word to leave out files that contain it (invoice -draft). Use OR between words (report OR invoice). A search written this precisely is not loosened or spell-corrected. Plain words work too: invoice yesterday, notes last week, tax pdf.
Typos and loose wordsMisspell a word and Summonly looks for the nearest word in your own files, and tells you what it searched for. If one word of a long search matches nothing, files that match the rest still appear. A question such as how do buyers get their license key finds files that contain those words.
RankingA name that matches comes first, then the file you open often and recently, then newer files. Opening a file teaches it, and you can clear what it has learned.
Find by meaningOptional, and off until you turn it on in Settings. It uses a small English-language model built into macOS to suggest documents on the same subject, below the word matches. It runs on your Mac and helps rather than guarantees: related documents are suggested, not proven.
Ask questionsOptional, and off until you turn it on in the first-run window or in Settings. Summonly then reads inside your documents (PDFs page by page, Word, PowerPoint, Excel, notes and text files) in the background, newest first. It answers a question such as which file mentions the refund policy with the file and the passage, and gives the page number for a PDF. Start with a question word, end with a question mark, or begin with ? to ask. It finds the words you use, so a question worded very differently from the document is found less often. When nothing matches well, it says so and shows the ordinary results. The text it reads is kept in a separate file in Summonly's folder in Application Support, which you can delete in Settings. It reads only while the Mac has power and is not hot, stops at a size limit, and skips files whose names suggest secrets.
Why isn't it found?In Settings, choose a file and Summonly says whether it is indexed. If it is not, Summonly names the rule that applies: outside your folders, hidden, inside a build folder, left out by you, in iCloud and not downloaded, or too large to read inside. Right-click a result for Why this result, Hide this result, or Leave this folder out. Command-Delete hides the selected result, and Settings lists what you hid so you can show it again.
Stays currentA result for a file you have deleted is not shown, and the file is dropped from the index. Files on a drive that is not connected are hidden and come back when it is. Settings has Check index, which tests the index and tells you plainly if something is wrong. Indexing slows down when the Mac is hot or the battery is low.
Quick answersSums, percentages (20% of 150, 150 + 20%), powers, square roots and other functions, and conversions between units of length, weight, volume, time, data, speed and temperature, such as 5 km in miles.
Quick toolsType uuid, base64 hello, base64 decode, urlencode, sha256 text, md5 text, #ff8800 or rgb(255, 136, 0), epoch, epoch 1700000000, slug Some Title, snake, kebab, camel, upper, lower, title, count some words, or password 24. The answer is one line and Return copies it. A generated password is copied marked as private, so other clipboard tools skip it, and it is cleared from the clipboard after a minute. Nothing is sent anywhere.
SystemType sleep, lock (turns the display off), screen saver, quit safari, force quit notes, or wifi, bluetooth, displays and sound to open that System Settings pane. These need no permission beyond the one Summonly already has. Restart and shut down are not included. Force quit asks before it acts. A switch in Settings opens Summonly when you log in.
Web searchType a keyword and some words: g for Google, ddg for DuckDuckGo, w for Wikipedia, maps for Apple Maps, yt for YouTube, gh for GitHub, scholar for Google Scholar.
Google, alwaysWhatever you type, a small Google button appears beside the search box, and Shift-Return does the same from the keyboard. It opens the search in your default browser, so it follows your own choice of browser. The button says Google in words. It does not use Google's logo. Nothing is sent until you press it.
Ask an assistantclaude, gpt and ppl open Claude, ChatGPT or Perplexity in your browser with your words already typed in, for example claude why is the sky blue. Type ask and a question to get one row for each assistant. Any text you type also gets three last rows, Search Google, Ask Claude and Ask ChatGPT, unless the line is a calculation or a command that already has its own answer. In Settings you choose which of them appear as those last rows, and you can add any other site that takes a search address with {query} in it. Pressing Return opens the page in your browser. Nothing is sent before that, the words go to that site and not through Summonly, and you use your own login there. Summonly does not talk to any assistant itself.
Clipboard historyOption-Shift-V, or type clip. It does not record anything copied from a password manager or marked private by the app that copied it. It also skips text that looks like a card number, a one-time code, an access token, a long key, or a password with upper and lower case letters, a digit and a symbol. You choose how many items to keep and for how many days, and can keep history in memory only. Pin items you want to keep, and clear it at any time.
SnippetsSave text under a keyword. {date}, {time} and {clipboard} are filled in when you use it. Summonly copies the snippet. You paste it where you want it.
FoldersDesktop, Documents, Downloads and your Applications folders to start, or your whole home folder if you choose it (Library and the Trash are always left out). The first-run window lets you choose these and every other option. Add or remove folders in Settings, and leave any folder out. If macOS refuses a folder, Summonly says so in its status line. Changes apply at once, without reopening Summonly. Files whose names suggest secrets, such as .env files, key files and names with password or secret in them, are found by name only: nothing inside them is read. Hidden files and developer folders such as node_modules and .git are skipped.
Connected drivesExternal SSDs, USB drives and other partitions are searched by file and folder name, so a file on a drive turns up like any other. Files on a drive are not opened unless you add a folder on it in Settings. Network drives, app installers and Time Machine backups are left out. Summonly follows drives as you connect and eject them, and stops reading a drive as soon as you eject it. Leave any folder on a drive out in Settings, or turn drives off. On our own Mac, with about 780,000 names in the index, most searches answer in under 30 milliseconds, one or two letters included. A misspelled word can take about a fifth of a second the first time.

Privacy

Works offline

Summonly needs no network connection for any of its features except two. One is opening a web search in your browser. The other is its check for a new version, which carries the app's name and version.

The index stays on your Mac

The index holds file names, paths and the start of text files, in Summonly's own folder in Application Support. You can rebuild it or delete it, and you choose which folders it covers.

Clipboard history is off until you turn it on, and skips secrets

Summonly does not read the clipboard at all until you choose to. It then skips password managers and anything an app marks as private, skips text that looks like a card number, token or long key, and can be kept in memory only. Where it is saved, the file is readable only by you.

Details are on the privacy page.

Folder access

The first time Summonly reads your Desktop, Documents or Downloads folder, macOS asks whether to allow it. Allow the folders you want searched. Summonly does not need Full Disk Access. It also reads the clipboard to keep history, and recent versions of macOS may ask you to allow that. If you add a folder that macOS protects, it will ask for that one too. The first time Summonly reads an external or USB drive, macOS asks once whether to allow it. The first index of a large folder or drive can take a few minutes and runs in the background at low priority.

What it is not

A replacement for all of SpotlightIt searches the folders you choose and, by name, your connected drives. It does not search Mail, Messages, Contacts or Calendar, or the web.
A workflow toolThere are no workflows, scripts or extensions in this version. It is for finding, opening, copying and calculating.
A chat assistantIt does not answer questions in sentences. The meaning search only suggests related documents.
SyncedEverything stays on your Mac. There is no account and no sync.
Cross-platformMac only. There is no Windows, iPhone or iPad version.

Frequently asked questions

What does it need to run?
macOS 14 (Sonoma) or later. macOS asks permission before Summonly can read your Desktop, Documents and Downloads folders.
How is it different from Spotlight?
Summonly searches the folders you choose, ranks by name and by what you open, answers sums and unit conversions, keeps a clipboard history that skips secrets, and runs web searches from a keyword. Spotlight also searches Mail, Messages and other content that Summonly does not.
Does it send my files or searches anywhere?
No. The index and the clipboard history stay on your Mac. Web searches open in your browser, and then your browser sends them.
What does Find by meaning do?
It suggests documents on the same subject, using a small English-language model that is part of macOS. It is optional, indexes in the background, and is helpful rather than exact.
Does it record passwords I copy?
Not from a password manager, and not text that looks like a card number, a one-time code, an access token, a long key, or a password with upper and lower case letters, a digit and a symbol. The check is a set of rules, so a password made only of letters, or any other unusual secret, can be recorded. It is cautious but not perfect, so you can also turn clipboard history off or keep it in memory only.
Can I change the shortcut?
Summonly opens with Option-Space, and clipboard history with Option-Shift-V. You can record different shortcuts in Settings.
Can it search inside Word documents?
Yes. It reads the text of Word, Excel, PowerPoint and OpenDocument files, the start of text, code and Markdown files and RTF files, and the first pages of PDFs for ordinary search. If you turn on question search it reads whole documents. Pages and Keynote files are found by name only.
Can it search an external SSD or a USB drive?
Yes. Connected drives are searched by file and folder name, and files on a drive are not opened unless you add a folder on it in Settings. Network drives, app installers and Time Machine backups are left out. macOS asks once before Summonly can read a removable drive. You can leave folders on a drive out, or turn drives off, in Settings.
Does one license work on more than one Mac?
One license key works on two of your Macs. Paste the same key into Summonly on each one.
Are updates included?
Yes, all of them. The price is a single payment, for life. Summonly checks for a new version and offers to install it in place.
What happens when the trial ends?
The trial is the complete app for seven days from the first time you open it, with no account. To keep using Summonly after that, buy it. You get a license key by email and on the page after you pay. Choose Enter License Key from the menu bar and paste it. It works offline.

How do I get help?
Email ben@purplelink.llc. If you lose your download link, the Find a purchase page emails it again to the address you paid with.
Why not Alfred or Raycast?
If you want workflows, extensions or built-in AI, use one of them. Summonly has none of those in this version. It is for finding files in the folders you choose, opening apps, doing sums and unit conversions, and keeping a clipboard history, and it costs $9.99 once after a 7-day trial. Alfred has a free core and a paid Powerpack. Raycast has a free plan and a Pro plan at $10 a month or $96 a year.
Does it work offline?
Yes. The file index and the clipboard history are kept on your Mac, and searching them needs no connection. Web searches and the Claude, ChatGPT and Perplexity rows open in your browser, which needs a connection. Pasting a license key works offline. The optional question search needs a one-time download of a search model, about 76 MB, from purplelink.llc, which you start in Settings. Opening Settings first fetches a small signed description of the model so it can show the size.
