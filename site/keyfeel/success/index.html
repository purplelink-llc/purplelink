In Keyfeel, choose Enter License Key from the menu and paste it. It unlocks Keyfeel for good, with no account, and works offline. It is also in your receipt email.

Installing

Open the disk image

Drag Keyfeel to Applications, then open it from there. It needs macOS 13 or later. It runs free for 7 days until you enter the key.

Allow Input Monitoring

On first launch macOS asks for the Input Monitoring permission. Keyfeel needs it to be told when a key is pressed. It reads which key, never the characters you type. If you miss the prompt, the switch is under System Settings, Privacy & Security, Input Monitoring.

It updates itself

The app checks for new versions and offers to install them in place. You can also choose Check for Updates from its menu.
