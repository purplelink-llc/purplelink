Overleaf version history on the free plan: keep older versions yourself

By Benjamin Ampel · November 27, 2026

On the free plan, Overleaf's History panel shows edits from the last 24 hours and any labelled versions. Full project history is a paid feature. If you need last month's draft, you have to keep it yourself, and that takes one download per milestone.

On this page

  3. Compare two versions
  4. What a paid plan adds

Disclosure: I make ModernTex, a Mac LaTeX editor, and it comes up near the end. The history rules below come from Overleaf's page on history and versioning and its premium features page, read on November 27, 2026.

What the free History panel shows

Overleaf's history page says: "For users on our free plan, the History panel will show edits made in the last 24 hours as well as any labeled versions." The same page calls full project history "a premium feature," and the premium features page lists the ability to revert to earlier versions against "only 24 hours of history availability on a free Overleaf account."

Labels are the free plan's one way to keep a point in time visible. The history page shows how to label a version, but it does not say whether free accounts can create labels. Open the History panel in your project. If it lets you label a version, label each milestone (submitted, after reviews, resubmitted).

Keep your own snapshots

The dependable free route is a download. Overleaf's history page says that Download as source (.zip) in the File menu downloads "the current version of the project." Do it at each milestone:

  1. Open the File menu and choose Download as source (.zip).
  2. Rename the zip with the date and the milestone, such as 2026-11-27-submitted.zip.
  3. Download the PDF too. It is the version a reviewer saw, and it opens without a TeX install.
  4. Keep both in a folder that your normal backup covers.

This takes about a minute and gives you every version you will want later: the submission, the revision and the camera-ready copy. It does not give you the edits between milestones. If you need those, download more often while you write.

Compare two versions

Two zips are enough for a marked-up comparison. The free LaTeX Diff tool takes the old and new files and returns a PDF with additions and deletions marked, then deletes the files from the server. The guide to showing changes between two LaTeX versions covers latexdiff for a response to reviewers.

What a paid plan adds

Full project history, the ability to restore older versions, and track changes. Overleaf's plans page listed these prices in US dollars on November 27, 2026: Student $98 a year or $13 a month, Standard $199 a year or $25 a month, and Pro $399 a year or $45 a month, each with a 7-day trial. Some universities pay for Overleaf through a site licence, so ask your library before you pay.

History on your own machine

On your own computer, history has no time limit. If you know Git, run git init in the unzipped project folder and commit after each work session. Git is free, runs locally and does not need Overleaf's paid Git integration.

ModernTex is my option if you would rather not use Git. It keeps revision snapshots you take at any point (before a revision, after peer review, before resubmission) and compares any two of them in a diff. It costs $19.99 once after a free 7-day trial and needs macOS 14 or later. It is a single-user app, so keep Overleaf for any draft several people type in at once. The LaTeX editor for Mac comparison covers the free editors as well.

Frequently asked questions

How much version history does the Overleaf free plan keep?
The History panel shows edits from the last 24 hours plus any labelled versions. Full project history is a paid feature. This is from Overleaf's history and versioning page, read November 27, 2026.
How do I keep an old version of an Overleaf project for free?
Open the File menu and choose Download as source (.zip). Overleaf says this downloads the current version. Rename the zip with the date and milestone, and download the PDF too.
Can I restore an older version on the Overleaf free plan?
Overleaf lists reverting to previous versions as a premium feature, against 24 hours of history on a free account. Keep your own dated downloads if you may need an older draft.
How do I compare two versions of a LaTeX project?
Download both versions and run latexdiff on the main files. It produces a PDF with deletions and additions marked. Purplelink's free LaTeX Diff tool does this online and deletes the files afterwards.
