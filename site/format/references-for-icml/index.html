ICML reference format

ICML asks for APA reference format with author-year citations. In LaTeX that means natbib plus icml2026.bst, both set up by the ICML 2026 style files.

Checked 2026-10-01 against the sources linked at the end of this page.

What ICML expects

  • Reference style: APA reference format, “regardless of your formatter or word processor”, with authors' last names and year in the text.
  • BibTeX style: icml2026.bst with natbib, both named in the example paper.
  • Style file: \usepackage{icml2026} for submission, \usepackage[accepted]{icml2026} for the camera-ready.
  • Length: Main body up to 8 pages, then any number of pages for references and appendices. The camera-ready body may be 9 pages.
  • Review: Double-blind. Refer to your prior work in the third person, and leave out acknowledgements, grant numbers and links to public repositories.

Setting up the bibliography

From the ICML 2026 example paper, at the end of the document:

\bibliography{example_paper}
\bibliographystyle{icml2026}

Replace example_paper with the name of your .bib file. The style file loads natbib, so \cite gives (Author, Year) and \yrcite gives the year alone.

LaTeX template

ICML publishes its own kit each year. The 2026 kit is icml2026.zip, which contains icml2026.sty, icml2026.bst and example_paper.tex. ICML had not published a 2027 kit when this page was checked.

Common mistakes

  • Unprotected capitals. The author instructions give the fix: put braces around a proper name in the .bib entry, such as {Markov}, so it keeps its capital.
  • Reusing last year's kit. The style and .bst file names carry the year, and the call says papers that do not use the correct style files are rejected without review.
  • Outdated entries. The instructions ask authors to keep the bibliography current, including names and venues, and ICML 2026 ran an automated reference check on accepted papers.
  • Using “et al.” for two authors. The example paper reserves it for citations with three or more authors.

Frequently asked

What bibliography style does ICML use?

icml2026.bst with natbib. The ICML 2026 example paper says to use APA reference format and names those two files as the way to get it in LaTeX.

Do references count toward the ICML page limit?

No. The main body is up to 8 pages, followed by any number of pages for references and appendices.

Where is the ICML LaTeX template?

In icml2026.zip, linked from the ICML 2026 author instructions and call for papers.
