How it works

You ask for a place

Press a shortcut, choose an action from the menu bar, or drag a window to a screen edge or corner. While you drag, a preview shows where the window will land.

Panely moves the window

It moves and resizes the front window through the macOS Accessibility permission. It reads each window's position, size and title, and nothing that is inside the window.

It remembers

Restore returns a window to its size before the first snap. Saved layouts bring back a whole arrangement, and Panely keeps one automatically for each set of displays you use.

What it does

SnappingHalves, quarters, thirds, two thirds, fourths, three fourths and sixths of the screen, plus maximize, full height, full width, almost maximize, center and a larger center, and make a window larger or smaller by a step. Each snap can leave a margin around the screen and a gap between windows, from 0 to 32 points.
ShortcutsMost actions have a default shortcut, such as Control-Option with an arrow key. In Settings, click any shortcut and press the keys you want, including for the sixths, which have none to start with. Panely refuses combinations that macOS keeps for itself or that another action already uses, and warns you when another app holds one. Any shortcut can be reset or turned off. Panely uses macOS's own system for global shortcuts, so it does not need the Input Monitoring permission and does not see other keys you press.
DraggingDrag a window to the left or right edge for a half, to the top edge to maximize, to the bottom edge for a bottom half, or to a corner for a quarter. A translucent preview shows the result before you let go.
Repeat to resizePress a left or right half shortcut again and the window steps to two thirds, then one third, then back to half. This can be turned off.
DisplaysMove a window to the next or previous display and it keeps its proportions. Panely orders displays left to right.
RestoreReturn a window to the size and place it had before its first snap.
Custom areasDefine your own places, up to twelve, such as a reading column in the middle 60% of the screen. Set the left edge, top, width and height as percentages in Settings, or place a window where you want it and choose Save this window as an area from the menu bar. Each area can have its own shortcut and appears in the menu bar. Areas are fractions of the screen, so they fit any display.
Ignored appsChoose apps whose windows are never moved, by shortcut or by dragging, such as a game or a video call. Open the menu bar icon while that app is in front and choose Never move windows of it.
LayoutsSave the arrangement of your open windows under a name, and apply it from the menu bar. Windows are matched by app, and by title when an app has several windows. Apps with no open window are listed instead of guessed at.
Describe a layoutType something like Xcode left, Simulator right, Terminal bottom. Panely reads the words with fixed rules on your Mac, asks you when an app name matches more than one app, and tells you which parts it could not read.
MonitorsPanely keeps an automatic layout for each arrangement of displays. When you plug a display back in, it waits a few seconds for macOS to settle and then puts windows where they were.
Windows it can reachPanely works on the windows you can see in the current Space. macOS gives apps no way to move windows between Spaces, so it does not.

Privacy

Works offline

Panely needs no network connection for any of its features. There are no accounts. The only network use is its check for a new version, which carries the app's name and version.

Positions, sizes and titles

To move a window, Panely reads where it is, how big it is and its title, so a saved layout can tell two windows of one app apart. It does not read what is inside a window.

No keystroke access

Shortcuts use macOS's own global shortcut system. Panely does not need Input Monitoring and cannot see which other keys you press.

Details are on the privacy page.

The Accessibility permission

When Panely first opens, macOS asks you to allow it under System Settings, Privacy & Security, Accessibility. That is the permission an app needs to move other apps' windows. Without it Panely can still be opened, but it cannot move anything. You can switch it off again in the same place.

What it is not

Automatic tilingIt does not rearrange windows by itself. It acts when you ask: a shortcut, the menu, a drag, or a layout you apply.
An AI appIt does not use a language model. Describing a layout works from a small set of fixed rules, and says when it cannot read a phrase.
A window recorderIt reads window positions, sizes and titles. It does not read, store or send what is inside a window. Saved layouts keep window titles on your Mac, and a title can contain a document name or a web address.
Cross-platformMac only. There is no Windows, iPhone or iPad version.

Frequently asked questions

What does it need to run?
macOS 14 (Sonoma) or later, and the macOS Accessibility permission.
macOS already snaps windows when I drag them. Will they fight?
They can. If you leave both on, a drag to an edge may be snapped twice. Settings tells you when macOS's own edge tiling is on and has a button that opens the right System Settings pane, where you turn off Drag windows to screen edges to tile.
Does it use AI?
No. Describing a layout in words is done by fixed rules on your Mac, with no model and no network. If a phrase is unclear it asks or says so; it does not guess.
Can it see what is in my windows?
No. It reads each window's position, size and title, which it needs to move and match windows.
Will it put windows back when I reconnect a monitor?
It is built to. Panely remembers where windows were for each arrangement of displays and, a few seconds after the arrangement changes back, puts the windows where they were. It only places windows that are open, and only those in the current Space.
Does it work with Spaces and full-screen apps?
It moves windows in the Space you are looking at. It does not move windows between Spaces, and macOS full-screen windows are managed by macOS.
Can I change the shortcuts?
Yes. In Settings, click a shortcut and press the keys you want. Panely refuses combinations that macOS keeps for itself or that another action already uses. Any shortcut can be reset or turned off.
Does one license work on more than one Mac?
One license key works on two of your Macs. Paste the same key into Panely on each one.
Are updates included?
Yes, all of them. The price is a single payment, for life. Panely checks for a new version and offers to install it in place.
What happens when the trial ends?
The trial is the complete app for seven days from the first time you open it, with no account. To keep using Panely after that, buy it. You get a license key by email and on the page after you pay; choose Enter License Key from the menu bar and paste it. It works offline.
