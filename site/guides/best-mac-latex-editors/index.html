What about Typst?

Typst is a separate typesetting language with its own compiler, not a LaTeX editor. A .tex file does not open in it, and LaTeX packages do not carry over. Version 0.15.1 came out in July 2026. Most journals still ask for LaTeX or Word source. A few accept Typst: IJIMAI keeps an official Typst template, for example. Check your target journal's author instructions before you switch. If you write in Typst on a Mac, the web app at typst.app and the Tinymist extension for VS Code are the usual starting points. ModernTex is a LaTeX editor and does not compile Typst. Read October 31, 2026.

What you actually need to run LaTeX on a Mac

A LaTeX editor is only half of the setup, and this trips up most people coming to LaTeX on a Mac for the first time. You need two things:

  1. A TeX distribution. This is the engine that turns your .tex source into a PDF. On macOS that is almost always MacTeX, which bundles the TeX Live distribution with a few Mac-specific applications. It is a large download, around 5 GB, because it ships every package you might ever cite.
  2. An editor. This is where you write. It sends your file to the distribution, shows you the resulting PDF, and tells you what went wrong when the compile fails. This is the part you get to choose, and it is what the rest of this page compares.

The distinction matters because a lot of "LaTeX won't work on my Mac" problems are really "no TeX distribution is installed". If you open a .tex file and nothing compiles, install MacTeX first and then pick an editor. The one exception is Overleaf, which runs the distribution on its own servers, so nothing is installed locally at all.

macOS does not include a TeX distribution, and neither Pages nor TextEdit will compile LaTeX. There is no built-in option the way there is for Markdown previewing.

The shortlist

  1. TeXShop: free, ships with MacTeX, the default for most academics.
  2. Texifier (formerly Texpad): paid, polished, modern Mac native.
  3. Octree: free, AI-assisted, web-based with Mac wrapper.
  4. VS Code + LaTeX Workshop: free, general-purpose code editor with a strong LaTeX extension.
  5. Overleaf: web-based, collaborative, runs in any browser.
  6. ModernTex: $19.99, native macOS, focused on the academic manuscript workflow.

Those six are the ones worth a real look. Nine more that run on a Mac are covered further down, including TeXstudio and Texmaker. Each has a short note on why it is not on the shortlist.

TeXShop

Cost: Free. Platform: macOS-only. Installed by: almost every academic with a Mac and MacTeX.

TeXShop is the editor that ships with the MacTeX distribution. It has been around for over 20 years, and Richard Koch at the University of Oregon actively maintains it. It does one thing well: edit a .tex file and compile it with whatever engine MacTeX provides. It has a side-by-side editor and PDF preview, SyncTeX click-to-source, basic syntax highlighting and multi-file support via root document declaration.

What it's good at: reliability. Compatible with every TeX distribution macro you'll encounter. No telemetry, no cloud, no subscription. If a tutorial says "open TeXShop and...", that's a feature.

What it lacks: modern UX (the interface looks like 2010), no inline BibTeX autocomplete, no plain-language error messages, no built-in tracked-changes view. Searching across a multi-file project is functional but not great.

Pick TeXShop if you want the closest thing to a default and you don't mind the dated interface. Most senior researchers do, in fact, pick TeXShop.

Texifier (formerly Texpad)

Cost: $39.99 per seat from the developer's store, $44.99 on the Mac App Store (US). Platform: macOS + iOS. Last release: 1.9.33, January 23, 2026 (both read October 31, 2026).

Texifier is the polished Mac-native option that most people who actually shop for a LaTeX editor end up with. It bundles its own TeX distribution (no MacTeX install required). It has incremental typesetting (the PDF updates as you type with no manual compile) and a structure sidebar that maps your manuscript by sections. It also has the best autocomplete-for-LaTeX experience available.

What it's good at: the "it just works" experience. Outline sidebar makes navigating a long manuscript feel natural. The iPad app is usable. Active development.

What it lacks: deep bibliography tooling. The BibTeX autocomplete is good but not specifically built for academic writing workflows. Tracked-changes via latexdiff requires external tools.

Pick Texifier if you want a polished, modern Mac-native experience and you're willing to pay $40 for it. This is the right answer for most working researchers writing journal-length manuscripts on a Mac today.

Octree

Cost: Free tier with limits, paid plan ~$10/mo. Platform: Web + Mac wrapper.

Octree is the newer entrant. It adds AI-assisted writing (suggestions, grammar, rewrites) on top of a competent LaTeX editor. Its design is cloud-first, so your project lives on Octree's servers and is accessible from any device.

What it's good at: AI-assisted drafting. If you want copilot-style suggestions while you write, Octree is the only mainstream option that integrates them well.

What it lacks: on-device privacy. Your manuscript is on Octree's servers by default. For sensitive research (medical, military, IP), that's disqualifying.

Pick Octree if AI-assisted writing is core to your workflow and your research isn't sensitive. Avoid if "no cloud" is a requirement.

VS Code + LaTeX Workshop

Cost: Free. Platform: cross-platform.

If you're a developer who also writes academic papers, VS Code with the LaTeX Workshop extension is the path of least resistance. Build chains are configurable, snippets are mature, Git integration is the same as your code projects. SyncTeX preview works well.

What it's good at: consistency with the rest of your toolchain if you spend most of your day in VS Code. Free, extensible, version-controllable settings.

What it lacks: a manuscript-first feel. VS Code is a code editor, so the document feels like a code file, not like a paper. Outline navigation works but isn't built for chapters and bibliographies.

Pick VS Code if you already live in VS Code and want one less context switch. The setup, and the spawn latexmk ENOENT error some people hit on a first build, are in VS Code and LaTeX Workshop on a Mac.

Overleaf

Cost: Free tier (limited compile time, no Git sync). Paid: Standard $199 a year or $25 a month, Student $98 a year, per Overleaf's plans page, read October 12, 2026.

Overleaf is browser-based and collaborative. It is the de facto choice for multi-author papers where co-authors aren't all comfortable installing LaTeX. The collaboration model (Google Docs-style) works.

What it's good at: multi-author collaboration. Templates for major journals. No local install required.

What it lacks: offline access on the free tier, Git sync on free, native-Mac feel. The editor itself runs in a browser.

Pick Overleaf if you need real-time collaboration. Many academic teams use Overleaf for collaboration and a native editor for solo writing.

If a large project hits the free tier's compile time limit, see what to do about an Overleaf compile timeout.

ModernTex

Cost: $19.99, one-time, all updates included, forever, after a free 7-day trial. Platform: macOS 14+. Status: shipping since September 2026. Updated often since launch; the release list is on the product page.

I built ModernTex because the existing options miss a few things that matter for academic manuscript work. It explains compile errors in plain language (BibTeX-style cryptic errors are the #1 frustration for new users). Its BibTeX autocomplete searches by author or title across your entire .bib. Revision snapshots are tied to ideas, not files. Submission-readiness checks catch journal-specific issues before you upload. A live TikZ figure editor builds flowcharts and diagrams by dragging boxes instead of writing coordinates by hand.

Why a new editor when Texifier exists: Texifier is excellent. However, it targets general LaTeX users (programmers, technical writers, students). ModernTex narrows the focus to academic manuscript writers (the workflow of writing a journal article or dissertation chapter, from outline to camera-ready). That is a deliberate constraint.

What it lacks: a track record. Version 1.0 shipped in September 2026, so it has none of the twenty years of edge-case coverage TeXShop has, and no iPad app. It needs MacTeX or TinyTeX, and offers a one-click TinyTeX install if neither is found.

Pick ModernTex if you write journal articles or dissertation chapters on a Mac and the manuscript-first features above are what you keep wishing for. The trial is free for seven days. Keeping it is $19.99, once.

Nine more LaTeX editors that run on a Mac

Every one of these works on macOS today. They are not on the shortlist because, for someone choosing an editor on a Mac in 2026, one of the six above does each one's best job better. The exception is TeXstudio, which is the right answer for a specific person: anyone who also works on Windows or Linux.

TeXstudio

Cost: Free, open source. Platform: macOS, Windows, Linux.

The most widely installed LaTeX editor that is not tied to one platform. It began as a fork of Texmaker and has grown well past it. It has an integrated PDF viewer with SyncTeX, a structure panel for long documents, autocomplete for commands and references, wizards for tables and figures, and spell-checking as you type. It is a Qt application, so it does not look or behave like a Mac app. Menus, shortcuts and dialogs feel like they were designed elsewhere, because they were.

Pick TeXstudio if you move between a Mac and a Windows or Linux machine and want the identical editor on both. If you only write on a Mac, TeXShop does the same job and feels native.

Texmaker

Cost: Free. Platform: macOS, Windows, Linux.

Texmaker is the editor TeXstudio was forked from, and its original author still maintains it. It is simpler for that: it has a built-in PDF viewer, SyncTeX, Unicode, spell-check, code folding, and less of everything else. If you opened TeXstudio and found it busy, this is the same idea with fewer panels.

Pick Texmaker if you want a cross-platform editor and TeXstudio felt like too much. Otherwise the same advice applies: on a Mac alone, TeXShop.

TeXworks

Cost: Free. Platform: macOS, Windows, Linux. Installed by: you, already, if you installed MacTeX.

TeXworks ships inside MacTeX and TeX Live, and was deliberately modelled on TeXShop's simplicity so that other platforms would have something like it. It has a source window, a PDF window, SyncTeX and a typeset button. That is the whole editor. It is fine for a first document and you will outgrow it by the second chapter.

Pick TeXworks if it is already on your machine and you need to compile something today. Then pick something else.

LyX

Cost: Free, open source. Platform: macOS, Windows, Linux.

LyX is not a LaTeX editor in the sense of the rest of this page. It is a document processor that generates LaTeX for you: you work in a structured, roughly formatted view and rarely see a backslash. For a thesis written alone, where you never need to hand a .tex file to anyone, that can be pleasant. The moment a journal template, a co-author, or a fussy figure needs raw LaTeX, you are fighting the tool. It still needs a TeX distribution installed.

Pick LyX if you want LaTeX output without writing LaTeX and will never share source. Most academics eventually need to share source.

Archimedes

Cost: Paid, one-time. Platform: macOS, with an iOS version.

Archimedes is a native Mac editor for Markdown with LaTeX math, with live preview and a math-focused toolbar. It is built for writing notes, problem sets and math-heavy documents, not for compiling a full journal manuscript with a bibliography and a class file. It is good at what it is for, which is not what most of this page's readers are doing.

Pick Archimedes if your LaTeX is mostly equations inside otherwise plain documents. For a paper, use one of the six above.

TeX64

Cost: Paid. Platform: macOS.

TeX64 is a newer native macOS editor. It compiles locally through the MacTeX or TeX Live installation you already have, rather than bundling its own distribution the way Texifier does. It is recent enough that I would not yet rely on it for a deadline, for the same reason I say that about ModernTex: no track record. Worth watching if native-Mac matters to you and you already have MacTeX installed.

Pick TeX64 if you want a native app, do not want a second TeX distribution on disk, and are comfortable being an early adopter.

Emacs with AUCTeX

Cost: Free. Platform: anything.

AUCTeX plus RefTeX is, feature for feature, one of the most capable LaTeX environments that exists. It offers inline previews of equations, cross-reference and citation lookup that understands your whole project, folding, and a compile loop you can bend to any shape. The learning curve is the entire Emacs learning curve. If you already live in Emacs you know this and did not need this page. If you do not, this is not the week to start.

Pick AUCTeX if you are already an Emacs user. Nobody else.

Neovim or Vim with VimTeX

Cost: Free. Platform: anything.

VimTeX is excellent. It handles compilation, syntax, text objects for environments and commands, folding, and forward and inverse search when paired with a PDF viewer such as Skim on the Mac. The same caveat as Emacs applies. It rewards people who already think in Vim and punishes everyone else.

Pick VimTeX if Vim is already how you write everything. Otherwise VS Code with LaTeX Workshop gives you most of the benefit with none of the modal editing.

JetBrains IDEs with TeXiFy-IDEA or LaTeX Pro

Cost: TeXiFy-IDEA is free, open source (MIT). LaTeX Pro is paid, with a 7-day trial. Platform: plugins for IntelliJ Platform IDEs.

TeXiFy-IDEA is a free plugin that adds LaTeX support to IntelliJ IDEA. Its installation guide uses IntelliJ IDEA Community, which is free. LaTeX Pro is a paid plugin for IntelliJ Platform IDEs from a different developer, Jetplugins. Its October 2026 release added a TikZ designer and an equation editor. TeXiFy-IDEA needs a TeX distribution installed; its Mac instructions name MiKTeX, and I have not checked whether LaTeX Pro needs one. Not tested by me. Everything here is what the makers state on their own pages, read October 22, 2026.

Pick a JetBrains plugin if you already write code in a JetBrains IDE and want LaTeX in the same window. Otherwise one of the six above is simpler.

Sublime Text with the LaTeXTools package and BBEdit with its TeX syntax highlighting also exist. Neither adds anything the nine above do not, so they are not covered separately.

Installing LaTeX on a Mac: MacTeX, BasicTeX, or Overleaf

Whichever editor you land on, the install order is the same: distribution first, editor second. And "MacTeX vs Overleaf" is not really an either-or. One is a distribution you install, the other is a website that installs nothing. The question is whether you want LaTeX on your own machine. If you are weighing that move, Overleaf alternatives for Mac covers what you give up and how to move a project.

MacTeX is the standard choice. Download the package from the TeX Users Group, run the installer, and you have TeX Live plus TeXShop, BibDesk and LaTeXiT. It is about 5 GB installed. Nearly every tutorial you will read assumes this is what you have, which is a real advantage when something breaks at 11pm before a deadline.

BasicTeX is the same distribution trimmed to roughly 100 MB. It omits most packages, so you install them individually with tlmgr as documents demand them. Worth it if disk space is tight, painful if you are new, because a missing package surfaces as a compile error rather than a prompt.

Homebrew works too, via brew install --cask mactex or mactex-no-gui. Same distribution, managed alongside your other packages.

Installing nothing is also an option. Overleaf runs entirely in the browser. For a single co-authored paper on a borrowed machine that is often the right answer, and you can move to a local setup later without changing your source files. The Purplelink LaTeX to PDF compiler will also build a document without any local install if you just need one PDF.

For the steps, sizes and a check that it worked, see how to install LaTeX on a Mac.

Apple Silicon no longer needs any special handling. MacTeX has shipped native arm64 binaries for years, and every editor on this page runs natively on M series hardware.

Which LaTeX compiler to use on a Mac

People search for the best LaTeX compiler for Mac, and the answer is that it is not a Mac question. MacTeX ships all three engines you would ever choose between, and every editor above lets you pick. pdfLaTeX is the default, the fastest, and what nearly every journal template assumes. Start there.

XeLaTeX adds system fonts and proper Unicode, which matters for non-Latin scripts or a document that must use a specific typeface. LuaLaTeX does what XeLaTeX does and is where newer packages are heading. Switch engines only when a package or a font forces you to, not because one is "best".

Frequently asked

Is there a free LaTeX editor for Mac?

Yes, several. TeXShop is free and arrives with MacTeX, so most people already have it. VS Code with the LaTeX Workshop extension is free. Overleaf has a free tier with limits on compile time and no Git sync. Of the paid options, Texifier is a one-time $39.99 rather than a subscription.

How much does Overleaf cost compared with a Mac LaTeX editor?

Overleaf Standard is $199 a year billed annually or $25 a month billed monthly. Its paid Student plan is $98 a year (Overleaf's plans page, read October 12, 2026). ModernTex, which Purplelink makes, is free for seven days and then $19.99 once with updates included. TeXShop, TeXstudio and VS Code with LaTeX Workshop are free. Overleaf's paid plans are built for co-authors editing together, which is the main reason to pay for it.

Does macOS come with LaTeX?

No. macOS ships no TeX distribution and no LaTeX editor. You need to install MacTeX, or use a browser-based option like Overleaf.

What is the difference between a LaTeX editor and a TeX distribution?

The distribution compiles your document. The editor is where you write it and read the errors. MacTeX is a distribution, TeXShop and Texifier are editors. You need one of each, except with Overleaf, which provides both.

Which LaTeX editor is best for academic writing on a Mac?

For most researchers today, Texifier if you will pay for polish, TeXShop if you want the default that every tutorial assumes. Choose Overleaf instead when co-authors need to edit the same file at the same time.

Is TeXstudio available for Mac?

Yes. TeXstudio runs on macOS, Windows and Linux and is free. It is the best choice if you also work on another platform. On a Mac alone, TeXShop does the same job and feels like a Mac app, which TeXstudio does not.

MacTeX or Overleaf?

MacTeX if you want LaTeX on your own machine: it works offline, compiles faster on any recent Mac, and every native editor on this page needs it. Overleaf if co-authors need to edit the same document live, or you are on a machine you cannot install 5 GB on. Many people use both.

Which LaTeX compiler should I use on a Mac?

pdfLaTeX, unless something forces a change. It is the default in every editor here and what journal templates assume. Use XeLaTeX or LuaLaTeX when you need system fonts or full Unicode. All three ship with MacTeX.
