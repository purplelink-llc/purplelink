October 16, 2026
Update

Vitae 1.2.0

You can now add, edit and delete degrees under CV & Packages > Education (also in Settings > Profile); before, they could only come in from a CV import. Each degree can have a location, a start year, honors, a dissertation or thesis title and an advisor, and can be marked in progress so the CV says “expected”. Tidy spells degrees the usual way (PhD becomes Ph.D.), moves “Ph.D. in Biology” into degree and field, and merges duplicates into the fullest entry; you see every change first, and merged copies go to Recently Deleted. Education on the CV has no more stray commas, lists degrees in progress first, then the most recent, and the NIH biosketch lists training in order with its location. Papers can now be linked to the grants that support them: each grant has a Supported Work card listing its publications, then work still in progress, and each project has a Funding card. A paper can support several grants, and stays linked once it moves from review to published. Turn on “List each grant’s publications under it” in Customize to print each award followed by its papers; it is off unless you choose. Spotlight could keep a stale entry after a record changed; Vitae rebuilds its Spotlight index once after this update.

Update

Summonly 1.3.0

Faster search. Summonly keeps the names of your files in memory, so one or two letters now find matches in a few thousandths of a second instead of up to two thirds of a second on a large index. After a restart it reads only what changed while it was closed, instead of going through every folder again, and a full scan walks folders several times faster. The index takes about a third less disk space; it is rebuilt once after the update, in the background, and search keeps working while it does. Earlier versions install 1.3.0 through Check for Updates, or you can download it from the Summonly page.

ModernTex 1.10.1

Fixes for thesis and journal templates. With no saved engine, no % !TEX program line and no latexmkrc that sets one, ModernTex picks the engine from the preamble: LuaLaTeX for \DocumentMetadata, fontspec, unicode-math or polyglossia, XeLaTeX for XeTeX-only packages such as xeCJK or bidi, and pdfLaTeX for documents that check which engine they run on. A missing bibliography style such as agsm.bst now names the TeX Live package it comes with and offers to install it. After a failed build the preview shows a PDF only if ModernTex built it, so a PDF shipped with a template is no longer shown as your document. When the open file belongs to a main file that brings in chapters with \input, \include, \subfile or \import, the Outline lists the whole document. Earlier versions install 1.10.1 through Check for Updates, or you can download it from the ModernTex page.

ModernTex 1.9.1

Thesis templates that keep their class and style files in a folder such as Styles/, and add it to TeX's search path in .latexmkrc, now build. ModernTex still never runs that file, because it is Perl and could run any program; it reads it as text and uses only the search folders it adds inside the project (ensure_path or $ENV for TEXINPUTS, BIBINPUTS and BSTINPUTS), and Build Results lists the lines it did not use. ModernTex 1.9.0

New: Edit > Convert Accent Commands to Characters turns commands such as \'{a}, \c{c} and \~a into á, ç and ã, in the selection or the whole file, as one undo step. It follows the file's \usepackage[...]{inputenc} declaration: a file that declares latin1 is saved as Latin-1, so the bytes still match, and a file that declares utf8 or nothing is saved as UTF-8. Characters the encoding cannot store stay as commands, and a .bib file asks first. Also new: with direct PDF editing off, a double-click in the PDF jumps to the matching line of the source; ⌘-click still works. Earlier versions install 1.9.0 through Check for Updates, or you can download it from the ModernTex page.
