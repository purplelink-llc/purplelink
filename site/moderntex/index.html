In the app

Source and PDF, always in sync

New in 1.3

Two things nobody enjoys writing by hand

A TikZ diagram and a results table are both perfectly capable LaTeX, and neither is a pleasant place to start from a blank line and a syntax reference. ModernTex builds both visually and drops in the real source underneath: nothing hidden, nothing you couldn't have typed yourself.

TikZ Designer

Drag boxes and arrows into place, pick colors from a swatch, resize by the corner, connect two shapes by dragging between them. Start from a flowchart, pipeline, state machine, or tree preset, or a blank canvas. Reopen an existing diagram from the Figures menu to keep editing it instead of redrawing it.

Table Editor

Paste a range straight from Excel or Google Sheets and it lands in the right cells, growing the table if the data is bigger and leaving the rest untouched if it's smaller. Return moves down a row, ⌥Return breaks a line inside a cell, and dragging a column edge resizes it, the way a spreadsheet does, producing booktabs-style tabular underneath.

Features

Everything the manuscript needs

Multi-file manuscript navigation

Navigate complex projects with root file detection and a structured sidebar. Jump between chapters, sections, and bibliography files without losing context.

Three compile modes

Fast, Live, and Full compile modes let you move at the speed you need. Live mode keeps the PDF in sync as you type. Full mode does the deep pass before submission.

Synchronized PDF preview

Forward and inverse search: click the source to jump to the PDF, click the PDF to jump to the source. Side by side, always in sync.

Citation management

BibTeX autocomplete that searches your bibliography by author, title, or key, not only the keys you have already cited. Cite-as-you-type with smart suggestions from your .bib files.

Plain-language error diagnostics

LaTeX error messages are hostile by design. ModernTex translates them into clear explanations with suggested fixes, reducing the debugging spiral that breaks flow.

Submission readiness checks

Automatically check anonymization, page limits, required sections, and submission packaging before you hit send, so formatting problems are caught before a journal returns the paper.

Version snapshots

Take a snapshot at any point: before a major revision, after peer review, before resubmission. Diff between snapshots with meaningful context.

Live TikZ figure editor

Build flowcharts and diagrams by dragging boxes and drawing connections on a canvas. ModernTex generates the TikZ code as you go; insert it at your cursor when it's ready.

Table editor

Paste a range from Excel or Google Sheets straight into the right cells. Resize columns by dragging, set a table-wide font, and generate clean booktabs-style LaTeX underneath.

Native macOS experience

Built in Swift for macOS 14+. Native dark and light mode, system fonts, proper keyboard shortcuts, and performance that doesn't make you wait.

Before you install

What ModernTex needs.

A Mac running macOS 14 or later and a TeX distribution. MacTeX or TinyTeX both work, and you do not have to set either up first: if ModernTex cannot find one when you compile, it offers a one-click TinyTeX install right in the editor. After checkout you get a signed disk image: open it and drag ModernTex to Applications. Bookmark the download page; it always hands you the newest version.

Frequently asked questions

How do I get updates?
ModernTex checks for a new version once a day and offers to install it in place. You can also choose Check for Updates from the ModernTex menu at any time. Updates are included in the purchase, and each download is code-signed by Purplelink LLC.
What macOS version is required?
ModernTex requires macOS 14 (Sonoma) or later.
I lost my license key. How do I get it back?
Enter the email address you used at checkout on the Find a purchase page. If that address bought ModernTex, a new license key and your download page are emailed to that address. Any key you had before keeps working.
Is there a free trial?
Yes. The trial is the complete app for seven days from the first time you open it, with no account and nothing to enter. When it ends, the window shows a notice and a Buy button; your .tex files are ordinary files on disk and are not touched. When you buy, the receipt email includes a license key: paste it into the trial's "Have a license key?" and that same copy unlocks, with no reinstall. The trial copy does not update itself, so install the paid download from your receipt page once to get updates in place.
What does it cost?
$10, once, after a free 7-day trial. That covers every 1.x update. There is no subscription and no account; the optional AI features use your own Claude account.
How is ModernTex different from TeXShop or Overleaf?
ModernTex is a native macOS app designed specifically for the academic manuscript workflow. It is not a web app and not a general-purpose code editor. It combines multi-file manuscript navigation, synchronized PDF preview, BibTeX autocomplete that searches by author or title, plain-language error diagnostics, and submission-readiness checks. Designed for researchers, not programmers. See how the best LaTeX editors for Mac compare, or read what changes when you move from Overleaf to a Mac editor.
Why not just use a free editor like TeXstudio?
TeXstudio is free, cross-platform, and already parses compile errors into a readable list, so it's a legitimate choice, especially if you also work on Windows or Linux. ModernTex is narrower on purpose: Mac only, built around the manuscript workflow specifically. Three things TeXstudio doesn't do: BibTeX autocomplete that searches your whole .bib by author or title rather than just the keys already cited in the file, submission-readiness checks for what journals actually reject on, and an anonymized export for double-blind review. If none of those matter to you, TeXstudio is a perfectly good free option.
Does ModernTex support multi-file projects?
Yes. ModernTex has built-in multi-file manuscript navigation with root file detection and a structured sidebar for jumping between chapters, sections, and bibliography files without losing context.
