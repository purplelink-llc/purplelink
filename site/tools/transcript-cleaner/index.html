Transcript Cleaner

Turn a Zoom or Microsoft Teams transcript (.vtt), a subtitle file (.srt) or a text file with speaker labels into plain text you can read and quote. The WEBVTT header, cue numbers and timestamps are removed, and each speaker's lines are joined into one paragraph. If you code interviews in NVivo or MAXQDA, you can keep the timestamps instead, in the layout that program's help describes for importing a transcript. It does not summarise, correct or reword anything. Everything runs in your browser. Your file is never uploaded.

    What it changes and what it leaves alone

    • Removed. The WEBVTT header, NOTE and STYLE blocks, cue numbers and ids, start and end times, and caption tags such as italics and voice spans. The speaker name is taken from the cue and, if you keep names, written once before each turn.
    • Joined. Lines inside a cue become one line. Consecutive cues from the same speaker become one turn. A cue with no name stays with the speaker above it. When a file has no speaker names, a pause of more than 3 seconds starts a new paragraph.
    • Left as written. Every word, including spelling mistakes, false starts, repeated words and filler such as "um". Nothing is summarised, corrected, translated or reworded. The few changes to the text itself are listed under "Does it change the words?" below.

    Import into NVivo or MAXQDA

    The two "Keep timestamps" outputs keep one time per turn, so a coded passage in NVivo or MAXQDA can play the matching part of the recording. The words are cleaned as described above. The file needs times, so this works with .vtt and .srt files and with text that has a time on each speaker line. The layouts come from the programs' help pages, read on 16 October 2026. They have not been tried in a copy of either program.

    • NVivo for Mac or MAXQDA. Each turn is a paragraph that ends with its end time, such as Jane Doe: Thanks for making time. #00:00:06-5# for 6.5 seconds. Both programs read a time at the end of a paragraph as the end of that text and the start of the next. In NVivo 15 for Mac, open the audio or video file, turn on edit mode, and choose Import, then Files, then Transcript Rows (NVivo help). NVivo for Mac puts any text before a colon and a space into the Speaker column, so the result lists turns that have one. In MAXQDA, choose Import, then Transcripts, and pick the f4 and f5transcript entry, which uses this time format, or Transcript with Timestamps (MAXQDA help).
    • NVivo for Windows. NVivo 15 for Windows reads a .txt transcript only as delimited lines, so this output writes one line per turn: the time span, such as 00:00:03.1-00:00:06.5, a tab, the speaker, a tab, and the text. Open the audio or video file, turn on edit mode, click Import Rows on the Edit tab, set "Create one transcript row for each" to Tab Delimited Line, untick "File includes header row", and map Field 1 to Timespan, Field 2 to Speaker and Field 3 to Content (NVivo help).
    • Times. Times are rounded to a tenth of a second, the smallest step NVivo keeps. When people talk over each other, the NVivo for Mac and MAXQDA output raises a time that would come before the one above it to match it, because MAXQDA drops a time that goes backwards, and the page lists those turns so you can check them. The NVivo for Windows output gives every line its own start and end, so overlapping turns keep their real times. The "Put a time before each turn" option does not apply to these outputs.

    How to clean a Zoom or Teams transcript

    1. Get the transcript file. Download the transcript as a .vtt file. Zoom saves the transcript of a cloud recording as .vtt, and Microsoft Teams lets you download a meeting transcript as .vtt. An .srt file or a .txt file with speaker labels works too.
    2. Add the file. Drop it on the page or choose it. You can add several files at once.
    3. Pick the options. Choose readable text, or keep the timestamps for NVivo or MAXQDA. Then keep speaker names, put a time before each turn, join each turn into one paragraph, and remove bracketed sound tags such as [inaudible]. Changing an option updates every file at once.
    4. Check the preview. Read a few turns and compare them with your original file. The cleaner does not correct the words, so any error in the transcript is still there.
    5. Copy or download. Copy the text, or download it as a .txt or .md file.

    Questions

    If you record meetings on a Mac, the comparison of Mac apps for transcription, text to speech and OCR covers the apps that make the transcript in the first place.

    Is my file uploaded?
    No. The page reads the file with your browser and cleans it in a background worker on your device. The meter on the page counts the requests the page makes while it works. The only one is an anonymous usage count that names the file type (vtt, srt or text), never the file name or any of its text.
    Does it change the words?
    No. It does not summarise, correct, translate or reword anything. Spelling, grammar, false starts and filler words stay as they are. The changes to the text itself are small: line breaks inside a cue become spaces, repeated spaces become one, the HTML codes for ampersand, less-than, greater-than and non-breaking space that VTT files use are turned back into characters, and caption tags such as italics are removed. If you tick the sound tag option, a fixed list of bracketed tags is removed too.
    Which files and layouts can it read?
    It reads .vtt (WebVTT), .srt (SubRip) and .txt files. In a VTT or SRT file, speaker names are taken from voice tags such as <v Jane Doe> (the layout Microsoft Teams uses) or from a name and colon at the start of each cue, such as Jane Doe: (the layout Zoom uses). A .txt file can use Name: lines, or a line such as [Jane Doe] 00:00:05 above each turn. It was built and tested on sample files written from the published formats, not on real exports. If a real Zoom or Teams file comes out wrong, send the first few lines with the names changed to ben@purplelink.llc.
    Can I import the result into NVivo or MAXQDA?
    That is what the two "Keep timestamps" outputs are for. Your file needs times. The layouts follow the NVivo 15 and MAXQDA help pages, read on 16 October 2026. They have not been tried in a copy of either program, so check a few rows after importing. If one does not import, send the first few lines with the names changed to ben@purplelink.llc. The steps for each program are under "Import into NVivo or MAXQDA" above.
    How does it decide who is speaking?
    Voice tags are taken as written. For Name: labels, the start of a line counts as a speaker only when at least half of the cues start with a label, or when at least two different capitalised names each appear three times or more. Ordinary text such as Note: see page 4 is not mistaken for a speaker. A cue with no name stays with the speaker above it.
    What happens when people talk over each other?
    Cues stay in the order they appear in the file. If one cue holds two voice tags, or two lines with different names, each speaker gets their own turn. If a cue starts before the previous speaker's cue has ended, the result says how many times that happened.
    What does it do when there are no speaker names?
    A pause of more than three seconds between cues starts a new paragraph. In a text file with no times, the blank lines you already have are kept as paragraph breaks.
    Which sound tags are removed?
    Only when you tick the option, and only a fixed list in square or round brackets: inaudible, unintelligible, crosstalk, laughter, applause, music, silence, pause, noise and a few similar words, with or without a time inside the brackets. Any other bracketed text, such as [NAME] or [sic], stays.
    Does it remove names or other personal details?
    No. It only removes the structure of the file. Names, places and other details in what people said are left as they are, so check the text before you share it.
    How large a file can it handle?
    Up to 50 MB per file. A two-hour interview is usually under 1 MB. Files are cleaned in a background worker, so the page stays usable. The preview shows the first 200,000 characters. Copy and the downloads include everything.
