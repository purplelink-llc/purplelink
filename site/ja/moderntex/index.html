ソースと PDF が、いつも同期

1つのウィンドウに、プロジェクト、ソース、そこから作られる PDF がそろいます。

フォルダを開く

ModernTex がルートファイルを見つけ、章、図、.bib ファイルをサイドバーに並べます。今いる場所を見失わずに行き来できます。

書くと、ビルドされる

Live モードでは入力に合わせて PDF が作り直されます。ウィンドウのサンプルは Mac 上で0.5秒でコンパイルされ、サーバーは使いません。

クリックで両方向にジャンプ

ソースの行をクリックすると PDF の該当箇所へ、PDF をクリックすると、それを作った行へ移動します。

手で書きたくない2つの作業

TikZ の図や結果の表は、構文のリファレンスと空白の1行から始まるのが普通です。ModernTex は両方を画面上で作り、その下に本物のソースを挿入します。隠れた部分はなく、同じものを自分で書くこともできます。

TikZ エディタ

箱や矢印をドラッグして置き、色を選び、角で大きさを変え、2つの図形の間をドラッグしてつなげます。フローチャート、パイプライン、状態遷移図、ツリーのひな形か、空のキャンバスから始められます。既存の図は Figures メニューから開き直して、描き直さずに編集を続けられます。

表エディタ

Excel や Google スプレッドシートの範囲をそのまま貼り付けると、正しいセルに入ります。データが大きければ表が広がり、小さければ残りはそのままです。Return で下の行へ、⌥Return でセル内改行、列の境界をドラッグすると幅を変えられます。表計算ソフトと同じ操作です。裏では booktabs 形式の tabular が作られます。

原稿は、Mac 上の普通の .tex と .bib のフォルダのままです。 ビルドも Mac 上で行うので、時間制限はありません。 アカウントを作る必要も、解約するサブスクリプションもありません。

原稿に必要なもの

複数ファイルのナビゲーション

ModernTex はルートファイルを検出し、構造化したサイドバーを表示します。章、節、文献ファイルの間を、場所を見失わずに移動できます。

3つのコンパイルモード

Fast、Live、Full は、速さと網羅性を引き換えにするモードです。Live は入力中に PDF を最新に保ちます。Full は提出前に全工程を実行します。

同期する PDF プレビュー

前方検索と逆方向検索に対応しています。ソースをクリックして PDF へ、PDF をクリックしてソースへ。並べて表示し、常に同期します。

文献管理

すでに引用したキーだけでなく、文献ファイル全体を著者名、タイトル、キーで探せる BibTeX 補完です。引用を入力するとき、.bib ファイルから候補が出ます。

投稿前チェック

匿名化、ページ数、必須セクション、投稿用パッケージを送る前に確認し、体裁の問題で論文が返される前に気づけます。

バージョンのスナップショット

大きな改訂の前、査読の後、再投稿の前など、好きな時点で保存できます。2つのスナップショットは diff で比べられます。

バージョン 2 の新機能

分割エディタ、複数カーソル、プロジェクト全体の検索、Vim モード、視覚的な数式エディタ。HTML と EPUB の書き出し、knitr と PythonTeX、Zotero、ターミナル、リモートプロジェクト、マクロ、プラグイン、カスタムテーマも加わりました。

ネイティブな macOS アプリ

macOS 14 以降で動き、ライトとダークの設定に従い、標準の Mac のショートカットを使います。

暗号のようなエラーから、修正まで

LaTeX は間違いを自分の言葉で報告し、意味を読み解くのは利用者に任せます。ModernTex はエラーを平易な言葉に直し、修正案を示します。

LaTeX の出力

! Undefined control sequence.
l.42 As shown by \citeauthr
                           {smith2024}, the effect holds.

ModernTex の説明

LaTeX は42行目のコマンド \citeauthr を認識していません。多くはコマンドのつづりの誤りか、そのコマンドを定義するパッケージが読み込まれていないことが原因です。

修正案

- 削除: \citeauthr{smith2024}
+ 追加: \citeauthor{smith2024}

これは説明用の例で、アプリの画面の取得ではありません。文言はエラーによって変わります。

日本語の文書で使う

日本語で論文や報告書を書くときに気になる点と、ModernTex が今できることを、事実だけ書きます。

XeLaTeX と LuaLaTeX

ビルドは手元の TeX で行います。LuaLaTeX（LuaTeX-ja）と XeLaTeX の文書はそのままビルドできます。エンジンを固定したいときは、ファイルの先頭に % !TEX program = lualatex のように書きます。Full ビルドでは、LuaLaTeX と XeLaTeX でも biber が実行されます。

upLaTeX と pLaTeX

upLaTeX と dvipdfmx の組み合わせ専用のプリセットはありません。プロジェクトの latexmkrc（確認すると Full ビルドで実行されます）か、Full ビルド用の独自ビルドコマンドで指定できます。設定例はガイドにありますが、ModernTex では動作を確かめていません。

クラスファイルとテンプレート

LaTeX でコンパイルできるクラスはそのまま使えます。学会や大学のクラスファイルはプロジェクトフォルダに置いてください。クラスを Styles フォルダに置くテンプレートもビルドできます。jlreq や BXjscls などは tlmgr で入れます。

画面表示は英語、データは Mac の中

アプリの画面は現在、英語です。原稿は Mac 上で編集とコンパイルを行い、クラウド同期もデータ収集もありません。任意の AI 機能は Mac 上の Apple Intelligence か、ご自身の Claude または OpenAI のアカウントで動き、同意を確認してから使います。

雑誌への投稿、共著者とのやり取り、複数の原稿の並行、再投稿のたびの作業を抱えています。

技術担当の共著者

他の人の LaTeX プロジェクトに加わり、構造を理解し、コンパイルの問題を直し、壊さずに貢献します。

向かない場合: 複数の共著者が同じ文書に同時に入力する必要がある（その原稿は Overleaf のまま）、Windows、Linux、iPad で作業する、Mac に TeX ディストリビューションを入れたくない、のいずれかに当てはまる場合です。ModernTex は2026年9月に公開されたため、TeXShop や Texifier に比べて実績は多くありません。他の選択肢はMac 用 LaTeX エディタの比較（英語）にあります。

他のエディタから移る

Overleaf から

プロジェクトを zip で取り出すか、Overleaf のプランに Git があれば Git クローンで持ってきます。ビルドは Mac 上なので時間制限はありません。リアルタイムの共同編集はないため、共著者は Overleaf に残れます。

TeXShop や TeXstudio から

同じフォルダを開くだけで、変換するものはありません。変わるのは、平易な言葉のエラー説明、著者名やタイトルでの文献検索、投稿前チェックです。ModernTex は Mac 専用です。

VS Code から

LaTeX Workshop を入れた VS Code は無料で、とても自由に設定できます。ModernTex は、ビルド、PDF、文献、投稿前チェックを設定なしで使いたい人向けです。自分で環境を組むのが好きなら、そのままで構いません。
