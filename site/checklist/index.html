The submission checklist

One page, PDF, free

Twelve checks to run before you submit a paper, in the order that saves rework: compile, references, word limit, template, figures, methods, related work, anonymization, cover letter, files and the record of where it went. Each check has a tick box, one line on why, and the address of the tool that does it.

Download the checklist (PDF)

The submission checklist, by email

Twelve checks reviewers run first, as a one-page PDF, plus one note when a tool changes. No daily mail.

Unsubscribe from any email with one click. Privacy.

What is on it

  • Compile cleanly
  • Validate the bibliography
  • Confirm every reference exists
  • Check the word and page limits
  • Match the venue's template and reference style
  • Check the figures
  • Check the methods against the claims
  • Look for missing related work
  • Anonymize for double-blind review
  • Write the cover letter
  • Prepare the submission files
  • Record the submission
