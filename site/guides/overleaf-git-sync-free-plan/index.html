Overleaf Git, GitHub and Dropbox sync on the free plan

By Benjamin Ampel · November 27, 2026

Git integration, GitHub sync and Dropbox sync are all paid Overleaf features. On the free plan the way in and out is a download and an upload. That is slower than sync, but it works on every plan, and you can still keep full Git history on your own machine.

Disclosure: I make ModernTex, a Mac LaTeX editor, and it comes up near the end. The rules below come from Overleaf's pages on Git integration, GitHub synchronization, Dropbox and uploading files, read on November 27, 2026.

What the free plan leaves out

Each integration page says the same thing. "Git integration is a premium feature." "GitHub synchronization is a premium feature." "Dropbox synchronization is a premium feature." I found no free sync route in Overleaf's documentation.

The free route: download, edit, upload

  1. Download. In the project, open the File menu and choose Download as source (.zip). Overleaf says this is the current version of the project. Unzip it into a folder you keep.
  2. Edit locally. Work on the files in any editor and build with a local TeX install. The MacTeX vs BasicTeX guide covers the install on a Mac.
  3. Upload what changed. In Overleaf, use the Upload button at the top of the file list. Overleaf's documentation does not say how it treats a file with the same name as one already in the project, so open the file after the upload and check that your change is there.
  4. Agree on who holds the pen. Nothing merges your edits with a co-author's. If both of you change methods.tex on the same day, one set of edits is lost. Take turns by file or by day.

To start a new Overleaf project from a local folder, zip it and use the upload project option. The zip can hold up to 180 files, 50 MB and 7 MB of editable material. The Overleaf file limits guide covers what to do when a project is bigger.

Keep Git history yourself

Overleaf charges for its Git server, not for Git. In the unzipped folder, run git init once, then git add -A and git commit after each download or work session. Push the repository to GitHub or GitLab if you want a copy off your machine. You get full history and a backup for free, and Overleaf stays the place where co-authors read and edit.

When the paid route is worth it

Pay for it when you move changes between Overleaf and your machine every day, or when a co-author edits in Overleaf while you edit locally. Clone and push replace the download and upload steps, and Git merges edits to different parts of the same file. The guide to moving an Overleaf project to a Mac with Git has the steps. GitHub sync stops working if the project's editable files pass 7 MB, per Overleaf's GitHub page. Overleaf's plans page listed these prices in US dollars on November 27, 2026: Student $98 a year or $13 a month, Standard $199 a year or $25 a month, and Pro $399 a year or $45 a month, each with a 7-day trial. Some universities pay for Overleaf through a site licence, so ask your library before you pay.

A local editor on the free route

Any editor works on the downloaded folder, and the LaTeX editor for Mac comparison covers the free ones. ModernTex is my option. Its Overleaf sync uses Overleaf's Git address, so it needs the paid plan like any other Git client. On the free plan it opens the unzipped folder, builds it with MacTeX or TinyTeX, and its Get Changes and Send Changes commands work with your own GitHub or GitLab repository. It costs $19.99 once after a free 7-day trial and needs macOS 14 or later. It is a single-user app, so keep Overleaf for any draft several people type in at once.

Frequently asked questions

Is Overleaf Git integration free?
No. Overleaf's Git integration page says Git integration is a premium feature, and GitHub and Dropbox sync are premium features too. This was checked on November 27, 2026.
How do I get an Overleaf project onto my computer without Git?
Open the File menu and choose Download as source (.zip). This works on every plan and downloads the current version of the project.
How do I send local changes back to Overleaf on the free plan?
Use the Upload button at the top of the file list. Overleaf's documentation does not say how it handles a file with the same name, so open the file afterwards and check that your change is there.
Can I use Git with Overleaf without paying?
Not with Overleaf's Git server. You can still run Git on your own copy: download the project, run git init in the folder, and commit after each session. Push it to GitHub or GitLab for a backup.
