Free web tool

File to Markdown

Upload a PDF, Word, PowerPoint, Excel, HTML, CSV, or EPUB file and get clean Markdown. Converted on our server with Microsoft markitdown, then deleted.

Drop a file here or choose one

Files are not kept: they sit in a temporary folder on our server only while they are converted, then they are deleted.

How to convert a file to Markdown

  1. Click the dropzone (or drag a file onto it) to choose your file.
  2. Click Convert to Markdown and wait a moment.
  3. Copy the result or download it as a .md file.

What it accepts and how it checks a file

The converter takes PDF, Word (.docx), PowerPoint (.pptx), Excel (.xlsx), HTML (.html and .htm), CSV and EPUB files up to 20 MB. Other types, including older .doc files, are refused with a message listing what is allowed. An empty file is refused. The server also checks that the file really is what its name says: a PDF must start with the PDF signature, and the Office and EPUB formats must be zip-based files. A renamed file of the wrong kind is rejected.

Unlike some tools on this site, this one is not processed in your browser. The file is sent to our server, written to a temporary folder, converted there and deleted when the request ends. The conversion runs offline on a local copy, with no plugins and no outside services, so the file is not passed to any other service.

What the output looks like

The Markdown appears in a read-only box under the button. Use Copy Markdown to put it on your clipboard or Download .md to save it with the same name as your file and a .md ending. How much structure survives depends on the format. HTML and Word files keep headings, bold text, lists and tables, while a PDF mostly comes back as plain text. Page layout, fonts and colors are never kept, because Markdown has no place for them.

Two examples. A CSV that starts with the columns name and score becomes a Markdown table with a header row, one row per line of the file. An HTML page with a heading, a bold word, a bulleted list and a small table comes back as a heading, **bold**, a list and a Markdown table.

When it does not work well

  • Scanned PDFs hold pictures of pages, not text, so the result is empty or very short. If nothing can be extracted, the page says so instead of returning a blank file.
  • A file the parser cannot read gives the message “Couldn’t convert this file.”
  • Each network address has a daily conversion limit, currently 25. After that the page asks you to wait.

About this tool

This uses Microsoft markitdown to extract text and structure from your file and render it as clean Markdown. Use it to feed documents into LLM (large language model) pipelines, static sites, or plain-text workflows.

Which file types are supported?
PDF, Word (.docx), PowerPoint (.pptx), Excel (.xlsx), HTML, CSV, and EPUB. Plain text and image-only PDFs may produce limited output.
Is my file stored anywhere?
No. Your file is uploaded over an encrypted connection and written to a temporary folder on our server only while it is converted, then deleted.
Why does the output look incomplete for some PDFs?
Image-only (scanned) PDFs contain no extractable text, so the output is minimal. PDFs with embedded text convert better.
Is there a size limit?
Yes, 20 MB per file. The page checks the size before it uploads and the server checks it again.
Can it convert an older .doc or a PDF I have scanned?
Older .doc files are not accepted, so save them as .docx first. A scanned PDF has no text to extract, so the output is minimal unless the scan already carries a text layer.
Can I convert a web page by its address?
No. The tool only reads files you upload. It does not fetch addresses, so save the page as an HTML file first.
