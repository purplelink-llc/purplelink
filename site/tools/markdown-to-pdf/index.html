Free web tool

Markdown to PDF & Word

Paste Markdown (or upload a .md file) and download a clean .pdf or .docx. Powered by Pandoc. Headings, lists, tables, code, and LaTeX math all convert.

…or drag a .md file here. Max 2 MB.

Your content is not kept: it sits in a temporary folder on our server only while the result is built, then it is deleted. Contents are not logged.

How to convert Markdown to PDF or Word

  1. Paste your Markdown into the box, or drag in a .md file (up to 2 MB).
  2. Choose PDF or Word (.docx).
  3. Click Convert and download the result.

What happens to your text

Unlike some tools on this site, this one does not run in your browser. Pressing Convert sends your Markdown to our conversion server, which writes it to a temporary folder, runs Pandoc on it and returns the finished file to your browser. The folder is deleted when the request ends. A Word file is built directly by Pandoc. A PDF is built by Pandoc handing the document to pdfLaTeX, which is why PDF takes longer. The server gives up after 90 seconds, and the page tells you that the conversion timed out.

You can paste text or upload a file. Uploads must end in .md, .markdown or .txt and are limited to 2 MB, and pasted text has the same 2 MB limit. If you have both a file chosen and text in the box, the file is used until you type in the box again. The page shows a preview of the PDF and a download link named converted.pdf, or a download link named converted.docx for Word.

What is not carried over

  • Images. The converter replaces every image with its alt text before it builds the file, so a picture such as ![a chart](chart.png) appears as the words “a chart”. The server cannot read files from your computer and does not fetch image addresses.
  • Page layout. You get Pandoc’s standard document styling. There are no options for fonts, margins or a custom template.
  • Errors. If Pandoc rejects the input, for example because of a LaTeX error in a math expression, the page shows the start of Pandoc’s own error message so you can find the line.

A worked example

This short document uses a heading, a sentence with inline math, an image and a table:

# Title then Text with $x^2$ and ![a chart](chart.png). then a table with the columns a and b and one row holding 1 and 2.

Converted to Word or PDF, the heading stays a heading, the math is set as x with a superscript 2, the image becomes the words “a chart”, and the table keeps its two columns and its row.

About this tool

Going the other way, you can convert a research paper PDF to Markdown for an AI assistant.

This runs pandoc to turn Pandoc-flavored Markdown into a PDF (via pdfLaTeX) or a Word .docx document. Use it to turn notes, READMEs, or drafts into a file you can share.

What Markdown features are supported?
Headings, bold, italic, ordered and unordered lists, links, images, fenced code blocks, blockquotes, tables, and footnotes. LaTeX math between $…$ renders in PDF output.
Why does PDF take a few seconds?
PDF output compiles your document through a LaTeX engine, which gives typeset-quality results. Word output is usually faster.
Is my content stored?
No. Your Markdown is written to a temporary folder on our server only while the result is built, then deleted. Contents are not logged.
Can I include pictures?
Not through this tool. Images are replaced by their alt text, so the output has no pictures. If you need figures, convert the text here and add the images in Word, or build the document in LaTeX.
Is there a limit on how many files I can convert?
Yes. Each tool allows a limited number of conversions per network address per day, currently 25. When you reach it the page says so and asks you to try again the next day.
Can I write raw LaTeX inside the Markdown?
Math between dollar signs works in PDF output. Raw LaTeX goes straight to pdfLaTeX, which runs without shell access, so commands that run programs or read files outside the document do not work.
