Summonly

Summonly finds files, apps and clipboard history from one box. Press Option-Space, type a few letters and press Return. It keeps a small index of your folders on your Mac, answers sums and unit conversions, and runs web searches from a keyword.

Also in the Mac Suite, $54.99 once.

How it works

It indexes in the background

Summonly reads file names, and the start of text files and PDFs, in the folders you choose, and keeps a small searchable index on your Mac. macOS tells it when files change, so the index stays current.

You open it and type

Press Option-Space. Results appear as you type: a quick answer first if the text is a sum, a unit conversion or one of the quick tools, then files and apps, ranked by how well the name matches and how often you open them.

You act on a result

Return opens it. Command-Return shows it in Finder. Option-Return copies its path. A calculation, snippet or clipboard item is copied.

What it does

FindsFile and folder names, apps, and the start of text, code and Markdown files, RTF files and the first pages of PDFs. Word and Pages documents are found by name only for now.
AbbreviationsType vsc for Visual Studio Code, or te for TextEdit. Summonly matches the first letters of an app's words.
Filterskind:pdf, ext:docx, in:Documents, modified:today, modified:week, after:2026-01-01 and before:2026-03-01. Plain words work too: invoice yesterday, notes last week, tax pdf.
Typos and loose wordsMisspell a word and Summonly looks for the nearest word in your own files, and tells you what it searched for. If one word of a long search matches nothing, files that match the rest still appear, and a question such as how do buyers get their license key finds files that contain those words.
RankingA name that matches comes first, then the file you open often and recently, then newer files. Opening a file teaches it, and you can clear what it has learned.
Find by meaningOptional, and off until you turn it on in Settings. It uses a small English-language model built into macOS to suggest documents on the same subject, below the word matches. It runs on your Mac and helps rather than guarantees: related documents are suggested, not proven.
Quick answersSums, percentages (20% of 150, 150 + 20%), powers, square roots and other functions, and conversions between units of length, weight, volume, time, data, speed and temperature, such as 5 km in miles.
Quick toolsType uuid, base64 hello, base64 decode, urlencode, sha256 text, md5 text, #ff8800 or rgb(255, 136, 0), epoch, epoch 1700000000, slug Some Title, snake, kebab, camel, upper, lower, title, count some words, or password 24. The answer is one line and Return copies it. A generated password is copied marked as private, so other clipboard tools skip it, and it is cleared from the clipboard after a minute. Nothing is sent anywhere.
SystemType sleep, lock (turns the display off), screen saver, quit safari, force quit notes, or wifi, bluetooth, displays and sound to open that System Settings pane. These need no permission beyond the one Summonly already has. Restart and shut down are not included. Force quit asks before it acts. A switch in Settings opens Summonly when you log in.
Web searchType a keyword and some words: g for Google, ddg for DuckDuckGo, w for Wikipedia, maps for Apple Maps, yt for YouTube, gh for GitHub, scholar for Google Scholar.
Google, alwaysWhatever you type, a small Google button appears beside the search box, and Shift-Return does the same from the keyboard. It opens the search in your default browser, so it follows your own choice of browser. The button says Google in words; it does not use Google's logo. Nothing is sent until you press it.
Ask an assistantclaude, gpt and ppl open Claude, ChatGPT or Perplexity in your browser with your words already typed in, for example claude why is the sky blue. Type ask and a question to get one row for each assistant. Any text you type also gets three last rows, Search Google, Ask Claude and Ask ChatGPT, unless the line is a calculation or a command that already has its own answer. In Settings you choose which of them appear as those last rows, and you can add any other site that takes a search address with {query} in it. Pressing Return opens the page in your browser; nothing is sent before that, the words go to that site and not through Summonly, and you use your own login there. Summonly does not talk to any assistant itself.
Clipboard historyOption-Shift-V, or type clip. It does not record anything copied from a password manager or marked private by the app that copied it, or text that looks like a card number, a one-time code, an access token, a long key, or a password with upper and lower case letters, a digit and a symbol. You choose how many items to keep and for how many days, and can keep history in memory only. Pin items you want to keep, and clear it at any time.
SnippetsSave text under a keyword. {date}, {time} and {clipboard} are filled in when you use it. Summonly copies the snippet; you paste it where you want it.
FoldersDesktop, Documents, Downloads and your Applications folders to start. Add or remove folders in Settings, and leave any folder out. Changes apply at once, without reopening Summonly. Files whose names suggest secrets, such as .env files, key files and names with password or secret in them, are found by name only: nothing inside them is read. Hidden files and developer folders such as node_modules and .git are skipped.

Privacy

Works offline

Summonly needs no network connection for any of its features except opening a web search in your browser and its check for a new version, which carries the app's name and version.

The index stays on your Mac

The index holds file names, paths and the start of text files, in Summonly's own folder in Application Support. You can rebuild it or delete it, and you choose which folders it covers.

Clipboard history is on from the first launch, and skips secrets

It skips password managers and anything an app marks as private, skips text that looks like a card number, token or long key, and can be kept in memory only. Where it is saved, the file is readable only by you.

Details are on the privacy page.

Folder access

The first time Summonly reads your Desktop, Documents or Downloads folder, macOS asks whether to allow it. Allow the folders you want searched. Summonly does not need Full Disk Access. It also reads the clipboard to keep history, and recent versions of macOS may ask you to allow that. If you add a folder that macOS protects, it will ask for that one too. The first index of a large folder can take a few minutes and runs in the background at low priority.

What it is not

A replacement for all of SpotlightIt searches the folders you choose. It does not search Mail, Messages, Contacts or Calendar, or the web.
A workflow toolThere are no workflows, scripts or extensions in this version. It is for finding, opening, copying and calculating.
A chat assistantIt does not answer questions in sentences. The meaning search only suggests related documents.
SyncedEverything stays on your Mac. There is no account and no sync.
Cross-platformMac only. There is no Windows, iPhone or iPad version.

Frequently asked questions

What does it need to run?
macOS 14 (Sonoma) or later. macOS asks permission before Summonly can read your Desktop, Documents and Downloads folders.
How is it different from Spotlight?
Summonly searches the folders you choose, ranks by name and by what you open, answers sums and unit conversions, keeps a clipboard history that skips secrets, and runs web searches from a keyword. Spotlight also searches Mail, Messages and other content that Summonly does not.
Does it send my files or searches anywhere?
No. The index and the clipboard history stay on your Mac. Web searches open in your browser, and then your browser sends them.
What does Find by meaning do?
It suggests documents on the same subject, using a small English-language model that is part of macOS. It is optional, indexes in the background, and is helpful rather than exact.
Does it record passwords I copy?
Not from a password manager, and not text that looks like a card number, a one-time code, an access token, a long key, or a password with upper and lower case letters, a digit and a symbol. The check is a set of rules, so a password made only of letters, or any other unusual secret, can be recorded. It is cautious but not perfect, so you can also turn clipboard history off or keep it in memory only.
Can I change the shortcut?
Summonly opens with Option-Space, and clipboard history with Option-Shift-V. You can record different shortcuts in Settings.
Can it search inside Word documents?
By name for now. It reads the start of text, code and Markdown files, RTF files and PDFs.
Does one license work on more than one Mac?
One license key works on two of your Macs. Paste the same key into Summonly on each one.
Are updates included?
Yes, all of them. The price is a single payment, for life. Summonly checks for a new version and offers to install it in place.
What happens when the trial ends?
The trial is the complete app for seven days from the first time you open it, with no account. To keep using Summonly after that, buy it. You get a license key by email and on the page after you pay; choose Enter License Key from the menu bar and paste it. It works offline.
