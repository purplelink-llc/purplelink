Springer LNCS reference format

LNCS proceedings papers use Springer's llncs.cls with the splncs04.bst bibliography style. Citations are numbers in square brackets, and Springer encourages a DOI on every reference.

Checked 2026-10-01 against the sources linked at the end of this page.

What Springer LNCS expects

  • Reference style: Citations by number in brackets, not superscript: [9] for one, [4-6, 9] for several. The list may be in alphabetical order (preferred) or in order of citation.
  • BibTeX style: splncs04.bst, which sorts alphabetically.
  • Class: \documentclass[runningheads]{llncs} in Springer's sample paper.
  • DOIs: Springer strongly encourages DOIs in references and adds missing ones during production.
  • Length and review: Set by each conference, not by the series. Check the call for papers of the conference you are submitting to.

Setting up the bibliography

From Springer's sample paper, in place of its hand-written thebibliography block:

\bibliographystyle{splncs04}
\bibliography{mybibliography}

Both llncs.cls and splncs04.bst are in Springer's proceedings LaTeX package and on CTAN as the llncs package.

LaTeX template

Springer's conference proceedings guidelines link the Proceedings LaTeX2e package and the Word templates. The same class is on CTAN as llncs and on Overleaf. We do not have an LNCS template page yet.

Common mistakes

  • Using an older Springer .bst left over from a previous project. The current package ships splncs04.bst.
  • Expecting citation-order numbering. splncs04 sorts the list alphabetically, so numbers in the text will not run 1, 2, 3 in order of first mention.
  • Unprotected capitals. splncs04 lowercases titles, so “Microsoft COCO” and “U-Net” above only survive because they are in braces in the .bib entry.
  • Leaving out DOIs. Springer encourages them, and references that do not meet Crossref's requirements are reformatted in production.

Frequently asked

What bibliography style does LNCS use?

splncs04.bst, which ships with Springer's llncs LaTeX package and sorts references alphabetically.

How are citations written in LNCS?

As numbers in square brackets, not superscript. Springer's sample paper says square brackets and consecutive numbers are preferred, and that label or author-year citations are also acceptable.

Where is the LNCS LaTeX template?

On Springer's conference proceedings guidelines page as the Proceedings LaTeX2e package, and on CTAN as the llncs package.
