How to find files on a Mac when Spotlight cannot

By Benjamin Ampel · October 12, 2026

This how-to covers the common case where a file is on your Mac but Spotlight does not show it. It lists the causes, how to check and fix each one, and the other ways to search.

Disclosure up front: Purplelink, which publishes this site, makes one app on this list, Summonly (a free 7-day trial, then $9.99 once). It is new and it searches only the folders you choose. Where another tool is the better fit, I say so.

The Spotlight steps come from Apple's Mac User Guide pages, read on October 12, 2026, where Apple's current pages are written for macOS 27. I checked the Terminal commands on a Mac running macOS 27 on the same day. I describe third-party tools from their own pages, which I read on October 12, 2026. I did not install or test them. Menu names change between macOS versions, so where I am not sure of the exact wording I describe the path in general terms and say so.

The short answer

When Spotlight cannot find a file, the cause is usually one of six things. The folder may be on Spotlight's exclusion list, or the index may be stale. The file may be on an external or network volume, or it may be a placeholder that is only in iCloud. Spotlight may be unable to read the file's text, or the file may live in a place Spotlight leaves out, such as the Library folder. Each cause has a check that takes under a minute. If you only need the file today, search from Finder with a Kind filter. You can also use a tool that does not depend on the Spotlight index, such as Find Any File or EasyFind.

Below are a table of the causes, the steps for each, and a comparison of the options.

Step by step

1. Try Finder before anything else

Open a Finder window, press Command-F or click the search field, and type part of the name. Under the typed text, choose whether to search This Mac or only the current folder. A search limited to a folder that does not contain the file looks like a missed file. The exact words in that bar can differ by macOS version.

2. Check Search Privacy

Apple's guide for macOS 27 says to open System Settings, click Spotlight in the sidebar (you may need to scroll), then click Search Privacy in the lower-right corner. The list shows folders and disks Spotlight is not allowed to search. To include one again, select it and click the Remove button (minus sign). On macOS 14, Apple's guide places this under Siri & Spotlight, with the button labeled Spotlight Privacy. If an old backup disk, a work folder or your whole drive is in that list by mistake, that is your answer.

Apple's page warns that excluding files or folders can stop update notifications for some apps. Excluding your whole internal disk stops them completely.

3. Check which results Spotlight shows

In System Settings, Spotlight, Apple's macOS 27 guide lists Results from Apps and Results from System, where you turn on the apps and system items you want in results. A file type or app whose results are off will not appear. Older versions of macOS used a single list of search result categories. The wording differs, so look for a list of checkboxes in the same Spotlight settings.

4. Rebuild the index for one folder

Apple's article on rebuilding the index says to use System Settings, Spotlight (or Siri & Spotlight on some versions), then the Search Privacy (or Spotlight Privacy) button at the bottom. Add the disk or folder to the list and wait a few seconds. Select what you added, click the minus button, then click Done and quit System Settings. Spotlight then reindexes the folder, which can take time and may show a progress indicator in the Spotlight window. If you get an "unknown" or permissions error, Apple says your account may lack ownership of some items in that folder.

In Terminal, mdutil -s / prints the indexing status of the startup volume, and sudo mdutil -E / erases and rebuilds its index. Those options are in the mdutil usage text on macOS 27 as of October 12, 2026. Apple notes that reindexing can take some time, so try one folder first. The folder test also tells you whether the index is the problem before you rebuild anything larger.

5. External drives and network shares

Spotlight keeps an index per volume. Run mdutil -s /Volumes/YourDrive to see whether a mounted volume is indexed, and sudo mdutil -i on /Volumes/YourDrive to turn it on. The usage text lists -i (on|off) to turn indexing on or off. I am not certain which volume formats and network shares Spotlight indexes on every version. If the status says indexing is disabled and turning it on does not help, use a tool that searches without the index. Also check that the drive is not in Search Privacy.

6. iCloud placeholders

With Optimize Mac Storage on, older iCloud Drive files can be kept only in iCloud and show a cloud icon in Finder. Apple's guide says you need an internet connection to open them unless you download them first. To download one, Control-click the file and choose Download Now. To stop a folder or file being removed from your Mac, Control-click it and choose Keep Downloaded. Apple puts the setting under your name in System Settings, then iCloud, then Drive. Until the file is downloaded, its contents are not on your Mac, so a search for words inside it can fail.

7. Files whose text cannot be read

Spotlight finds a file by its name and details, and by its text when it can read the format. A scanned PDF is a picture of a page with no text underneath, so searching for a word on it finds nothing. If you can find the file by name but not by a phrase inside it, this is the likely cause. The fix is to search by name, or to run OCR (optical character recognition, which turns an image of text into searchable text) on the PDF first. Which other formats Spotlight can read varies, so I will not list them.

8. Library, system and hidden folders

Find Any File's page says it can find files in folders that are usually excluded from Spotlight search, such as the System and Library folders. If the file you want is in one of those, or in a hidden folder, Spotlight is not the tool. In Finder you can open the Library folder with Go to Folder from the Go menu, and show hidden files with Command-Shift-Period.

Search better with what is already on your Mac

Finder search and its operators

Apple's page on narrowing Finder search results describes two ways. First, type a search, press Return, and click the Add button below the search field. Then choose Kind from the first pop-up menu and a type such as Document or Image from the second. Second, type a keyword in the field. "New York City kind:images" is Apple's example, and the page has a table with kind:pdf, kind:folder and kind:email. Each criterion narrows the results, and an item must match all of them. For AND, OR and NOT, Apple says to hold Option and click the More button. A minus sign before a term excludes it. Keyword names vary slightly between macOS versions.

Spotlight syntax

The Spotlight window accepts the same kind of keywords. Apple's page documents kind:. I did not find the keywords people use beyond it, such as name: and date:, on an Apple page I read, so test them on your version. On macOS 27, a command line check with mdfind -interpret "name:index" matched a file by name on one Mac. That shows the Spotlight parser accepts name:. A bare word searches names and text, so a name search is narrower and quieter when you know the file name.

Terminal: mdfind

mdfind queries the same Spotlight index from Terminal. The macOS 27 manual page lists these options: -onlyin dir to limit the search to a folder, -name fileName for matching file names only, -count for the number of matches, -literal and -interpret for how the query is read, and -0 for NUL-separated output. Here are two forms of the command, which I ran on macOS 27 with other folders and names.

mdfind -onlyin ~/Documents -name invoice
mdfind -onlyin ~/Documents "kMDItemContentType == 'com.adobe.pdf'"

The first lists files in Documents whose names match. The second lists PDFs. If a file does not appear here, it is not in the Spotlight index, whatever the Spotlight window shows. This separates "Spotlight did not index it" from "I typed the wrong thing".

HoudahSpot

The product page calls it an advanced file search app that builds on Spotlight. You start with a simple search and refine it by adding and combining criteria such as name, text content, file extension, tags, dates, file size, resolution and author. You can save searches as templates. It offers a free trial and a Buy Now link, with no amount or trial length on the page. The page says it requires macOS 10.14 or newer with Spotlight indexing enabled. Because it builds on Spotlight, it cannot find what the index never saw, so the checks above still apply. Pick it if your problem is too many results, not missing ones.

Find Any File

The page says it lets you search for files on your disks by properties such as name, extension, date range, size and kind. It says the app is not meant to replace Spotlight. It can find files Spotlight does not, including those in folders usually excluded from Spotlight, such as the System and Library folders. It lists a price of 6 USD, with a Mac App Store option, and shareware you can try first. It says it can find text in plain text and in zip files including Word and Excel, and in PDFs if Spotlight has indexed them. Holding Option and choosing Find All starts a root mode that asks for an administrator password. That mode covers local volumes, including other users' home folders, but not network mounts. The page lists macOS 10.11 to 27. Pick it if the file is somewhere Spotlight never looks.

EasyFind

DEVONtechnologies' freeware page lists it as a free utility. It can search by name, content, tags or comments, and it supports Boolean operators, wildcards, phrases and regular expressions. The page says it does not require indexing and that version 5.0.2 requires OS X El Capitan or later. Pick it if you want a free tool with regular expressions and no dependence on the Spotlight index.

Alfred and Raycast

Both are launchers (apps that open files and run commands from a keyboard shortcut) that can find files. Alfred's file search page lists keywords: open to open a file, find to reveal it in Finder, and in to search inside file contents. It describes File Filters (custom searches by file type or scope) as a Powerpack feature. Raycast's file search page says it helps you find documents and see recently opened files, with actions such as copying the path or opening in Finder. The same page says searching external drives needs Full Disk Access. Neither page says which index it uses. The Alfred alternatives guide compares them with other launchers.

Summonly (Purplelink's)

Cost: free for 7 days, the complete app, then $9.99 once. Platform: macOS 14 or later. I make it, and this is described from its product page rather than from a test against the others.

Summonly keeps its own small index of the folders you choose. The default folders are Desktop, Documents, Downloads and your Applications folders, or your whole home folder if you choose it, with Library and the Trash always left out. Press Option-Space and type. It finds files, folders and apps by name. It reads the start of text, code and Markdown files and RTF files, the first pages of PDFs, and the text of Word, Excel, PowerPoint and OpenDocument files. Pages and Keynote files are found by name only.

It supports the operators this guide has been describing: quoted phrases, a minus sign to leave a word out, OR, name: and size:, and filters such as kind:pdf, ext:docx, in:Documents and modified:week. An optional question search, off until you turn it on, reads inside documents and shows the file and passage. It finds the words you use and can miss a question worded very differently from the document.

The part that matches this guide is the check in Settings. Choose a file and Summonly says whether it is indexed. If it is not, Summonly names the rule that applies. The possible rules are outside your folders, hidden, inside a build folder, left out by you, in iCloud and not downloaded, or too large to read inside. A file on a drive that is not connected is hidden and comes back when the drive does. Summonly does not need Full Disk Access, and macOS asks permission before it reads Desktop, Documents and Downloads.

What it does not do: it does not search Mail, Messages, Contacts or Calendar, and it will not find a file outside the folders you gave it. Spotlight searches more kinds of content than Summonly does. Pick it if the files are in your own folders and you want fast, precise search and a clear reason when one is missing.

Quick picks

  • Need the file now? Finder search with a Kind filter, then mdfind -name in Terminal.
  • File is in Library or a hidden folder? Find Any File.
  • Want free, with regular expressions? EasyFind.
  • Too many results? HoudahSpot, or operators in Summonly.
  • Want to know why one file is missing? Search Privacy, mdutil -s, or Summonly's check in Settings.

How to choose

  1. Run the cheap checks first. Search Privacy, a placeholder icon, and the search scope in Finder fix most cases and cost nothing.
  2. Ask whether the file should be in the index at all. Library files, hidden files and some external volumes are common exceptions.
  3. Match the tool to the problem. Missing files call for a tool that does not rely on Spotlight. Too many results call for better operators.
  4. Check what each tool needs from macOS. Full Disk Access and administrator passwords widen what an app can read, and the permissions guide explains both.
  5. Try before you buy. EasyFind is free, Find Any File and HoudahSpot offer trials, and Summonly has 7 days.

Frequently asked

Why can't Spotlight find a file I know is on my Mac?

The usual causes are a folder or disk on the Spotlight exclusion list (System Settings, Spotlight, Search Privacy), a stale index, an external or network volume, a file that is only in iCloud, a file whose text Spotlight cannot read such as a scanned PDF, or a file in a place Spotlight leaves out, such as the Library folder.

How do I rebuild the Spotlight index on a Mac?

Apple's article says to open System Settings, click Spotlight (or Siri & Spotlight), click Search Privacy (or Spotlight Privacy), add the folder or disk to the list, wait a few seconds, then remove it with the minus button and click Done. In Terminal, sudo mdutil -E / erases and rebuilds the startup volume's index. The menu names can differ by macOS version.

How do I search for a file type in Finder?

Type your search, press Return, click the Add button below the search field and choose Kind and a type, or type a keyword such as kind:pdf in the search field. Apple's page lists kind:pdf, kind:folder and kind:email among its keywords.

What is mdfind?

A Terminal command that queries the Spotlight index. Its manual page lists options such as -onlyin to limit the search to a folder, -name to match file names only, and -count to print the number of matches. If a file does not show up in mdfind, it is not in the index.

What can find files Spotlight cannot?

Find Any File says it can find files in folders usually excluded from Spotlight, such as the System and Library folders. EasyFind says it does not require indexing. Summonly, which I make, keeps its own index of folders you choose and can tell you why a given file is not found.

Does Summonly search everything Spotlight does?

No. It searches the folders you choose and does not search Mail, Messages, Contacts or Calendar. It adds operators, a clipboard history that is off until you turn it on, and a tool that explains why a file is not found.
