Beamer slides and poster template

By Benjamin Ampel · November 26, 2026

Beamer is the LaTeX class for slides, and the beamerposter package turns the same class into a conference poster. This page has one skeleton of each, the options you will change first, and the pitfalls that the package documentation and TeX Stack Exchange describe.

Both skeletons use packages that ship with TeX Live. The slides use the beamer class with the Metropolis theme (CTAN package beamertheme-metropolis), and the poster uses beamerposter. We read all three CTAN pages on 2026-11-26. A full TeX Live (MacTeX) has them. A small distribution such as BasicTeX or TinyTeX may need tlmgr install beamertheme-metropolis beamerposter first.

Minimal skeleton

Save each file in its own folder, or keep both in one folder and build them by name. Neither needs a .bib file. Build with latexmk -pdf slides.tex and latexmk -pdf poster.tex.

Download the starter (.zip) slides.tex, poster.tex and a README. Both files compile with pdfLaTeX, XeLaTeX and LuaLaTeX. Writing on a Mac? Open the folder in ModernTex.

Slides, 16:9

% Beamer slides, 16:9, with overlays and speaker notes.
% Build:  latexmk -pdf slides.tex
% Handout: change the first line to \documentclass[aspectratio=169,handout]{beamer}
\documentclass[aspectratio=169]{beamer}

\usetheme{metropolis}   % ships with TeX Live; best with XeLaTeX or LuaLaTeX (Fira Sans)

% Notes: uncomment ONE of these. Hidden by default.
% \setbeameroption{show notes}                     % notes pages follow each slide
% \setbeameroption{show notes on second screen}    % slide and notes side by side

\title{Talk title}
\author{First Author}
\institute{Department, University}
\date{\today}

\begin{document}

\maketitle

\begin{frame}{Outline}
  \tableofcontents
\end{frame}

\section{Motivation}

\begin{frame}{One claim per slide}
  \begin{itemize}
    \item First point appears first.
    \pause
    \item Second point appears on the next click.
    \pause
    \item Third point closes the slide.
  \end{itemize}
  \note{Say the number here. Spend about a minute on this slide.}
\end{frame}

\begin{frame}{Overlay specifications}
  \only<1>{This text is on slide 1 only.}
  \only<2>{This replaces it on slide 2.}

  \uncover<3->{This appears on slide 3 and stays.}
  \note[item]{Slide 3 is the result. Pause before you show it.}
\end{frame}

\begin{frame}[fragile]{Code needs the fragile option}
\begin{verbatim}
latexmk -pdf slides.tex
\end{verbatim}
\end{frame}

\begin{frame}[standout]
  Questions?
\end{frame}

\end{document}

To make the handout, add handout to the class options: \documentclass[aspectratio=169,handout]{beamer}. To see the notes, uncomment one of the two \setbeameroption lines.

Poster, A0 portrait

% Conference poster, A0 portrait, with beamerposter.
% Build:  latexmk -pdf poster.tex
% If the type looks small, raise scale; if it overflows, lower it.
\documentclass[final]{beamer}
\usepackage[size=a0,orientation=portrait,scale=1.4]{beamerposter}
\usepackage{graphicx}
\usepackage{lmodern}   % scalable sans-serif fonts at poster sizes

\usetheme{default}
\setbeamertemplate{navigation symbols}{}
\setbeamercolor{block title}{bg=black!70,fg=white}
\setbeamercolor{block body}{bg=black!5,fg=black}

\title{Poster title: the finding in one line}
\author{First Author \and Second Author}
\institute{Department, University}

\begin{document}
\begin{frame}[t]
  \begin{center}
    {\Huge\bfseries\inserttitle}\\[0.6em]
    {\LARGE\insertauthor}\\[0.3em]
    {\Large\insertinstitute}
  \end{center}
  \vfill
  \begin{columns}[t]
    \begin{column}{0.46\paperwidth}
      \begin{block}{Question}
        One or two sentences that state what you asked and why it matters.
      \end{block}
      \begin{block}{Method}
        \begin{itemize}
          \item Data and sample size.
          \item The model or procedure.
        \end{itemize}
      \end{block}
    \end{column}
    \begin{column}{0.46\paperwidth}
      \begin{block}{Result}
        The main figure goes here, at a readable size from two meters away.
      \end{block}
      \begin{block}{Conclusion}
        Three short lines. Add a contact line or QR code below.
      \end{block}
    \end{column}
  \end{columns}
  \vfill
\end{frame}
\end{document}

The two columns are sized from \paperwidth, so they follow the paper size you set in the package options. Replace the block text with your own and add figures with \includegraphics at a width such as 0.9\linewidth.

Key options

  • aspectratio=169: a 16:9 page, which matches most projectors and screens now. Beamer's default is 4:3.
  • handout: the class option that builds the handout version. Overlay steps collapse, so a frame with three \pause steps becomes one page. On our test build the slides skeleton is 11 pages as slides and 7 as a handout.
  • \pause, \only<2>{...} and \uncover<3->{...}: \pause reveals the rest of the frame one step at a time. \only puts material on the listed slides and removes it elsewhere. \uncover reserves the space, so the layout does not jump.
  • \note{...} and \setbeameroption: notes are hidden by default. show notes interleaves note pages with the slides, and show notes on second screen builds a two-screen version of the talk.
  • fragile and standout: [fragile] lets a frame hold verbatim text, and Metropolis's [standout] makes a closing slide with one line on it.
  • size=a0, orientation=portrait and scale=1.4: the beamerposter package options. The package readme lists these options: page size, orientation and a font scale. Raise scale if the text looks small, and lower it if the columns overflow.
  • Poster package choice: tikzposter is also in TeX Live, and CTAN lists it under the LaTeX Project Public License 1.2. We used beamerposter (LPPL and GPL on CTAN) because it extends the same beamer class as the slides, so blocks, columns, colours and themes work the way they do in a talk.

Common pitfalls

  • Metropolis falls back to the default font under pdfLaTeX. The theme's manual says to compile with XeLaTeX or LuaLaTeX to use the Fira fonts, and the package prints a warning if you do not. Run latexmk -xelatex slides.tex and install Fira Sans, as the theme's readme advises. If the log still says it could not find the fonts, they are not installed.
  • Verbatim text needs [fragile]. The Beamer user guide says a frame with verbatim or lstlisting must carry the fragile option. It adds that this means either no overlays in that frame or an external file written and read back, so plan a code slide as one step.
  • Overlay commands in handout mode. The user guide explains that an overlay specification with no mode name, such as \only<3>{Text}, is treated as a beamer specification, so in handout mode that text shows on every slide. Give the handout its own specification, for example \onslide<2| handout:0>. To drop a whole frame from the handout, write \begin{frame}<handout:0>.
  • Second-screen notes need a viewer that supports them. According to the user guide, show notes on second screen makes a superwide page, with the talk on the left half and the notes on the right, and not every presentation program supports it. The guide names PDF Presenter as one that does. Test it on the machine you will present from.
  • Figure and table numbers. Beamer captions carry no number by default. The user guide recommends the numbered caption option only if the audience has a printed handout with the same numbering. If you turn numbers on and they seem to vanish, a theme may be setting the structure colour to white. A TeX.SE answer traces this to the caption number using that colour and fixes it with \setbeamercolor{caption name}{fg=...}.
  • Old advice for beamerposter and newer beamer. The beamerposter readme says that with beamer 3.10 you must not use the option hyperref={pdfpagelabels=false}. Templates written before that version often still carry it, so delete it from an older poster.

Check before you present

  • Build from a clean folder with latexmk -pdf, with no leftover .aux or .nav files, and read the log for the Metropolis font warning and for overfull boxes.
  • Count the pages. The slides skeleton gives 11 with notes hidden, 7 as a handout and 17 with show notes on. If the file you project has more pages than slides, the notes are still on.
  • Step through every \pause in the PDF viewer you will present from, in full screen, on the projector's resolution if you can.
  • For the poster, check the page size in the PDF's document properties. In Preview, Tools and then Show Inspector lists it. The skeleton builds at 841 by 1189 mm, which is A0. Ask your print shop which size and bleed they want before you export.
  • Zoom the poster out until it is about the size of a letter page on your screen. If you cannot read the headings, the audience will not read them from a metre away.
  • The overfull hbox page explains the warning you will see most often when a poster column is too narrow for its text.
