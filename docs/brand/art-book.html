Three · construction

How the primary logo is built

  1. Wordmark width is 72 percent of the mark's width, centred beneath it.
  2. Gap between mark and wordmark is a quarter of the wordmark's height.
  3. Clear space on every side equals the height of the "softwares" line.
  4. Minimum size: 160 px wide on screen or 30 mm in print. Smaller than that, use the mark (at least 16 px).
  5. The wordmark is the original artwork, traced. It is never retyped in a site font.
Four · where each one goes

Use by surface

The rule underneath the table: on a surface about the company, use the primary logo. Where there is no room for the name, use the mark. Inside a product, sign it with the wordmark alone, small, at the bottom.

Seven · design log

Decisions, in order

  1. 2026-10-28

    Mark adopted

    Eight versions of a striped P-L monogram arrived. The mark was traced to a vector from the image's transparency, so its edges stay sharp at any size, and filled with a hue-310 gradient. The gradient was tuned twice until it read on both themes.

  2. 2026-10-28

    Same file names

    The new mark replaced the old files in place, so all 389 pages picked it up without markup edits. All 94 per-page social cards were re-rendered.

  3. 2026-10-29

    Primary logo is the lockup

    “The main one should be the purplelink softwares one underneath the new logo.” The wordmark sits centred beneath the mark at 72 percent of its width.

  4. 2026-10-29

    Wordmark alone inside products

    Circled Hoops should carry just “purplelink softwares” at the bottom. Generalised to every app, game and product video.

  5. 2026-10-29

    Logo files are versioned

    Browsers kept the old mark for up to 30 days. Every logo reference now carries a content hash, so a new logo reaches everyone on their next page load.
