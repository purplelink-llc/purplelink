Metadata Cleaner

Remove author names, GPS positions, camera details, comment authors and edit history from photos, PDFs and Word, Excel and PowerPoint files. A second tab strips invisible characters from pasted text. Everything runs in your browser. Your files are never uploaded.

JPG, PNG, WebP, PDF, DOCX, XLSX and PPTX. Up to 200 MB each.

      Files are read and rewritten in this tab. The only requests the page makes are for its own scripts. Your files and text are never sent anywhere.

      What it removes

      • Photos (JPG, PNG, WebP). EXIF, including camera make and model, serial numbers, date taken and GPS position. XMP and IPTC captions and bylines, comments, embedded thumbnails and Content Credentials. Pixels are not decoded or re-encoded, so quality does not change. The rotation tag is kept by default so a portrait photo does not turn sideways.
      • PDF. The document properties (author, title, subject, keywords, creator, producer, dates), the XMP packet, the file ID and private application data. Comment and markup authors. Photo metadata inside embedded JPEGs. Old versions of edited content that some PDF writers leave inside the file.
      • Word, Excel and PowerPoint. Author, last saved by, company, manager, template, title and the custom properties. The preview thumbnail. Names and dates on comments and tracked changes. The people list, editing-session ids, the attached template path and the folder an Excel workbook was saved in. Photo metadata inside embedded pictures.
      • Text. Zero-width characters, text-direction controls, hidden tag characters, soft hyphens, control characters and odd spaces. These break LaTeX builds and can carry instructions a reader cannot see.

      Cleaning a manuscript for double-blind review

      1. Clean the PDF you will upload. This removes the author and producer fields that reviewers can see in the document properties.
      2. Clean any Word or Excel supplement the same way, and leave the rename option on so comment authors read “Author”.
      3. Open the result in a PDF reader and check File, Properties. The author field should be empty.
      4. Metadata is only one way authors are identified. Names in acknowledgements, self-citations and file paths in figures are content. Anonymity Check reads the text for those.

      Questions

      Are my files uploaded?
      No. The page reads the file with your browser, rewrites it in memory and hands you the result as a download. There is no server step. The only requests the page makes are for its own scripts, such as the PDF library when you add your first PDF.
      How do I know the metadata is really gone?
      Each result is read a second time with the same reader that found the fields in the first place, and the page says what, if anything, is still there. For your own check, open the cleaned file in a PDF reader's properties dialog, or run a tool such as ExifTool on it.
      Does it change my photos or reduce their quality?
      No. JPEG, PNG and WebP are edited at the byte level: the metadata blocks are cut out and the image data is copied as it was. The file gets a little smaller and looks identical. Color profiles are kept so colors do not shift.
      Why does it keep the rotation tag?
      Phones store portrait photos sideways and add a tag that says which way is up. Removing every tag makes those photos appear rotated. The tag says nothing about you, so it is kept as a one-field replacement for the original block. Untick Keep photo rotation to drop it.
      What does it not remove?
      Anything that is content. Names written in a document's text, headers and footers, watermarks, visible stamps, and what a photo shows. It does not touch the file system dates your computer keeps, and it does not change pixels, so a face or a street sign is still there. Attached files inside a PDF and custom XML parts in an Office file are reported and left in place.
      Can I keep comments and tracked changes?
      Yes. They are always kept. Only the names, initials and timestamps on them are replaced, so reviewers can still see what changed but not who made the change. Untick the rename option to keep the names.
      What about password-protected or old-format files?
      Password-protected PDFs are refused because the file cannot be rewritten without the password. Remove the password in your PDF reader, then clean the result. The old .doc, .xls and .ppt formats are not supported. Open them in Word, Excel or PowerPoint and save as .docx, .xlsx or .pptx.
      What about video, OpenDocument and HEIC?
      Not yet. Export a HEIC photo as JPG on your phone or Mac first. Save OpenDocument files as Office files, or export to PDF and clean that.
