ModernTex Check: a free MCP server that checks LaTeX projects

By Benjamin Ampel · November 27, 2026

ModernTex Check gives an AI assistant four ways to check a LaTeX project on your Mac. It reads your files and reports what it finds. It never writes a file, never compiles, and does not need a TeX installation.

The Model Context Protocol (MCP, an open standard for connecting AI assistants to tools) lets a client such as Claude Code call a program on your computer and read its answer. ModernTex Check is one of those programs. It is free and MIT-licensed (source on GitHub), and it runs on macOS 14 or later on Apple silicon and Intel Macs.

The four tools

  • explain_error: reads a build log, or one pasted error message, and gives the file, line, matching log line and fix steps for each error and warning.
  • check_references: finds \ref and \cite keys with no matching \label, \bibitem or .bib entry. It follows \input and \include and suggests the key you probably meant.
  • check_manuscript: runs rule-based checks on structure, reported numbers, availability statements, repeated words and misspelled package names.
  • check_bib: reports duplicate keys, likely duplicate entries, missing required fields and implausible years, plus the clean-ups that would normalize the file. Your .bib is left as it was.

Every check is deterministic (no model runs inside the server), so the same file always gives the same answer. The assistant decides when to call a tool and how to use the result.

Install

Download ModernTex Check 1.0.0 (zip, 1 MB). The release page lists the checksums.

The download holds one universal binary, signed with a Developer ID and notarized by Apple. Put it in a folder you keep, such as ~/bin, and add it to your client.

Run it once in Terminal before you add it (~/bin/moderntex-check --version) and choose Open if macOS asks. An assistant cannot answer that prompt for you.

For Claude Code, run this in Terminal:

claude mcp add moderntex-check -- "$HOME/bin/moderntex-check"

For Claude Desktop, Cursor or any client that reads an mcpServers block, add this to its configuration file and restart the client:

{
  "mcpServers": {
    "moderntex-check": { "command": "/Users/you/bin/moderntex-check" }
  }
}

Replace /Users/you with your home folder. Then ask the assistant something specific, for example "Check the references in /Users/you/paper/main.tex" or "Explain the errors in /Users/you/paper/main.log."

Limits

Paths passed to the tools must be absolute. Files over 10 MB are refused. An \input or \include that points outside the root file's folder is not followed, so a project cannot pull in files from elsewhere on the Mac. explain_error gives better answers from the whole log (log_path) than from one pasted line, because the log carries the file and line of each error.

Where the checks come from

These are the same checks that ModernTex, my LaTeX editor for Mac, runs as you write. The server shares its code with the editor, so a fix to one is a fix to both. When a fix needs the editor (installing a missing package, for example), the tool result says so in one line. I make both, so weigh that when you read the results.

Frequently asked questions

Does ModernTex Check change my files?
No. All four tools only read. check_bib lists the clean-ups it would make to a .bib file and leaves the file as it was.
Do I need MacTeX or TinyTeX installed?
No. The server never compiles. If a TeX tree is installed, check_manuscript reads its package index to tell a missing package from a misspelled one. Without one, it compares package names against a built-in list.
Does it send my files anywhere?
The server makes no network requests. It answers the assistant over standard input and output on your Mac. The assistant then sends the tool result to its model, as it does with any tool.
