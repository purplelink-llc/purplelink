PDF Redaction Checker

Drop in a PDF you have redacted and see whether the text under the black boxes can still be read. The PDF never leaves your browser.

What this can and cannot tell you

  • It checks the text layer and simple dark shapes. A page that comes back clean is not proven safe.
  • It does not check images under boxes, text converted to outlines, hidden layers, attachments or older versions saved inside the file.
  • It cannot redact anything. It only checks the file you give it.

Up to 200 MB. Most files take a few seconds.

How to redact properly on a Mac

  1. Open the PDF in Preview.
  2. Choose Tools, then Redact. Preview shows the redact controls.
  3. Drag over the text you want to remove. Do not use the rectangle shape from the markup toolbar. A shape only covers the text.
  4. Close the document and choose to save. Preview applies redactions when the file closes, and it warns that redacted content is permanently removed.
  5. Open the saved file here and run the check again. Keep the original in a safe place, because the saved file cannot be undone.

Redaction does not clear the title, author and creator fields. The results list them so you can remove any that name someone.

If you redact transcripts or scanned documents often, Tapefolio finds many identifying details in transcripts and scans and replaces them with codes, and it misses some, so read the result before you share it. Free for 7 days.

Questions

Is my PDF uploaded?
No. The file is read in your browser with a copy of pdf.js hosted on this site, and nothing is sent anywhere. You can disconnect from the network after the page loads and it still works.
Why can text be read under a black box?
A black rectangle drawn over a page is a separate object on top of the text. The words are still in the file, so they can be selected, copied and searched. Redaction removes the words themselves.
What does the check actually do?
It draws each page in your browser, finds every word in the text layer and looks at the pixels where that word sits. If the area is solid dark with no light pixels showing, the word is under a box. It also reads shapes and markups added to the page, whether a scanned page has an OCR text layer, and the title, author and creator fields.
Does a clean result mean the file is safe?
No. It means this check found nothing. It does not look at images under boxes, text that was converted to outlines, hidden layers, attachments or older versions saved inside the file. Look at the result as one check, not a clearance.
Why does a scan show up here?
Many scanning apps add an invisible text layer so the scan can be searched. If a black box is drawn over a scan, or burned into it, that invisible text may still be under it. The page card says when a scan has an OCR text layer.
Can this tool redact a file for me?
No. It only checks. To redact on a Mac, use the steps on this page and run the check again on the saved file.
