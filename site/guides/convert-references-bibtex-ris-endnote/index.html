How to Convert References Between BibTeX, RIS, and EndNote

By Benjamin Ampel · September 24, 2026

Purplelink's Reference Converter converts citations between BibTeX, RIS, and EndNote formats entirely in your browser. This guide walks through the export, paste, and convert steps.

To convert references between BibTeX, RIS and EndNote, paste the exported records into the free Reference Converter, pick the target format and copy the result. It works in any direction and runs in your browser, so nothing is uploaded.

Steps

  1. Export your references from your current tool. In Zotero, select the items, then File > Export Library, and choose RIS. In EndNote, use File > Export and pick RIS or the EndNote tagged format. From a database such as Web of Science, PubMed or Scopus, use its export option and pick RIS or BibTeX.

  2. Open the Reference Converter and paste the exported text into the input box. Open the .ris or .bib file in any text editor, select all, and paste.

  3. Leave From on Auto-detect, or set it if you know the input format. Choose BibTeX, RIS or EndNote in the To menu.

  4. Click Convert. The converted records appear below the input.

  5. Click Copy and paste the result into your .bib file, or into a new text file saved as .ris. To bring RIS into Zotero, use File > Import and select that file.

What's happening under the hood

The converter reads each record into plain fields (title, authors, year, journal, DOI and so on), then writes those fields back out in the target format's syntax. BibTeX stores authors as "Last, First and Last, First"; RIS puts each author on its own AU line; EndNote uses a %A tag per author. Journal articles, conference papers, book chapters and books convert cleanly. Unusual entry types or non-standard fields can come through slightly altered, so scan the output before importing it.

Q&A

I pasted 40 references at once. Will all of them convert?

Yes. Paste an entire library export. The tool converts the whole block in one pass.

Some fields are missing in the output.

Fields with no equivalent in the target format are dropped. Missing DOIs or truncated abstracts reflect the source data, not the conversion.

My references contain accented characters like ü or é. Will they come through correctly?

The converter keeps accented characters as Unicode in every format. Current LaTeX engines read UTF-8 .bib files; if an older journal template rejects them, replace each one with its LaTeX accent command, such as {\"u} for ü.

After converting

Before a .bib file goes into a manuscript, run it through the free BibTeX Validator, which flags missing fields, duplicate keys and references that do not match a real DOI. The guide to common BibTeX errors explains what each warning means, and the BibTeX hub collects the related tools. If you only have a list of DOIs, get BibTeX from a DOI or arXiv ID instead.

Further reading: if you manage bibliographies in LaTeX often, The LaTeX Companion (3rd edition) covers BibTeX and biblatex styles in detail in Part II. There are more books on the research desk.
