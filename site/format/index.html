What each venue expects

A quick reference for what manuscript format, template, and bibliography format specific CS / IS / security venues use — with a free converter preset to the right output for each.

    Computer security
  • USENIX Security — USENIX Security Symposium
    Computer security
  • ACM CCS — ACM Conference on Computer and Communications Security
    Computer security
  • NDSS — Network and Distributed System Security Symposium

    Information systems
  • ISR — Information Systems Research
    Information systems
  • ACM CSUR — ACM Computing Surveys
    Computer science (survey articles)
