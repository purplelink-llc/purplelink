Five free Mac wallpapers

Five of Benjamin Ampel's travel photographs, sized for a Mac screen. Each comes in two sizes: 6016 by 3384 pixels for a 6K, 5K or 4K display, and 3456 by 2234 for a MacBook. Every file is cropped from the original to the screen's shape, never stretched. No account, no email needed.

Set one as your wallpaper

  1. Open System Settings and choose Wallpaper.
  2. Click Add Photo and pick the file. To rotate through all five, unzip the pack and click Add Folder instead.
  3. Choose Fill Screen. The files already match the screen's shape, so nothing important is cut off.

Shortcut: Control-click a file in Finder and choose Set Desktop Picture.
