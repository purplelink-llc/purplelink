Find the Intel apps on your Mac before macOS 28

By Benjamin Ampel · November 13, 2026

Apple says Rosetta stays available through macOS 27. From macOS 28 it covers only certain older games. Here is how to find the apps on your Mac that still need it, and what to do with each one.

Disclosure: I make Legroom, a disk space app. It does not list Intel apps; this guide uses only what is built into macOS. Apple's steps and dates come from its support page Using Intel-based apps on a Mac with Apple silicon (published September 21, 2026), which I read on November 13, 2026. I ran the Terminal command below on my own Mac the same day, on macOS 27.0.1.

What is changing

Rosetta is the part of macOS that lets an app built for Intel Macs run on a Mac with Apple silicon. It works in the background, so most people never notice it. Apple's page says Rosetta is available on any Apple silicon Mac through macOS 27. Starting with macOS 28, it will work only for certain older, unmaintained games that rely on Intel-based frameworks. Apple gives no date for macOS 28 on that page.

So an app that is Intel-only today will most likely stop opening on macOS 28 unless its maker ships an update. Apps marked Universal or Apple silicon are not affected. When you open an Intel app on macOS 27, macOS may already show a notice saying support is ending.

Check one app in Finder

  1. Open the Applications folder in Finder and click the app once.
  2. Choose File, then Get Info, or press Command-I.
  3. Read the line after Kind. Application (Intel) needs Rosetta. Application (Universal) and Application (Apple silicon) do not.

One exception: if a Universal app's Info window has "Open using Rosetta" turned on, it runs as an Intel app, usually so it can load an old plug-in. Update the plug-in, then turn that setting off.

The Intel-based Apps list in System Settings

On macOS 27, Apple added a list. Choose Apple menu, System Settings, then General, About. In the macOS section, click Details next to Intel-based Apps. Each entry has a More Info button that offers Show App in Finder or Move to Trash.

Apple describes the list as apps you used recently or that are installed in common locations, so it can leave some out. For a full list, use Terminal.

A full list from Terminal

Open Terminal (in Applications, then Utilities), paste this line and press Return. It only reads the list of apps macOS already keeps: nothing is installed, changed or sent anywhere.

system_profiler SPApplicationsDataType -json 2>/dev/null | awk -F'"' '$2=="_name"{k=""} $2=="arch_kind"{k=$4} $2=="path" && k=="arch_i64"{print "Intel\t" $4} $2=="path" && k=="arch_i32"{print "32-bit\t" $4}'

It prints one line per app: Intel or 32-bit, then where the app is. Universal and Apple silicon apps are left out. If it prints nothing, every app it found runs natively.

On my Mac it looked at 692 apps in about five seconds and printed four lines. One was an old App Store copy of a launcher app in Applications. The other three were leftover script runners inside a source code folder on an external drive, one of them 32-bit.

What to know about the list:

  • It searches more than Applications. It includes apps on external drives and apps tucked inside other folders, so expect a few you forgot about.
  • It lists apps only. Intel-only plug-ins, extensions, command-line tools and helpers inside an app are not in it. Apple notes those may need updating separately.
  • 32-bit apps are a separate case. macOS stopped opening them in 2019, before Apple silicon, and Rosetta never ran them. They do not work today.
  • It does not flag a Universal app set to Open using Rosetta. Finder's Get Info shows that.

What to do with each one

  • Update it. If it came from the App Store, check the App Store's Updates. Otherwise use the app's Check for Updates command or its maker's website, and look for a Universal or Apple silicon version.
  • Ask the maker if there is no update. Apple suggests contacting the developer to learn whether one is planned.
  • Find a replacement for an app its maker no longer updates, before you move to macOS 28.
  • Remove it if you no longer use it.

Removing the ones you no longer use

Drag the app to the Trash, or use its own uninstaller if it has one. That removes the app but not what it saved in your Library folder. The guide How to delete a Mac app and the files it leaves behind shows how to find those files by the app's bundle identifier and which ones are safe to remove. I make Legroom ($9.99 once after a 7-day trial), which shows where your disk space went, and that guide says where free tools do the same job.

Frequently asked

How do I know if an app needs Rosetta?

Select the app in Finder and choose File, Get Info. If Kind says Application (Intel), it needs Rosetta on a Mac with Apple silicon. Universal and Apple silicon apps do not.

Will Intel apps stop working in macOS 28?

Apple says Rosetta is available through macOS 27, and that from macOS 28 it will work only for certain older, unmaintained games that rely on Intel-based frameworks. Plan on other Intel-only apps not opening on macOS 28 unless their makers ship a Universal or Apple silicon version.

What about 32-bit apps?

They already do not open. macOS dropped 32-bit apps in 2019, before Apple silicon, and Rosetta never ran them. If the Terminal command lists one, you can remove it or look for a newer version.
